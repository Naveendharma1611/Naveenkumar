Module 1 — What Is Seaborn?

Built on Matplotlib · Tidy data · pandas · Figure-level vs axes-level

▼

🌊 Seaborn and its relationship to Matplotlib

Seaborn is a statistical data visualization library built directly on top of Matplotlib. Every seaborn plot ultimately draws using Matplotlib's Figure and Axes objects, but seaborn adds a higher-level interface that understands pandas DataFrames, computes common statistics automatically (means, confidence intervals, regression fits, kernel density estimates) and ships with attractive default themes. You do not need to re-learn plotting from scratch — if you know basic Matplotlib (figures, axes, plt.show()), seaborn feels like a statistics-aware shortcut layered on top of it, and you can always drop back down to raw Matplotlib calls to fine-tune a seaborn figure.

🧹 Tidy (long-format) data: what Seaborn expects

Seaborn works best with tidy (also called "long-format") DataFrames: one row per observation, one column per variable. For example, a tidy sales table has columns like date, region, product and sales — not a separate column per region. Most seaborn functions take a DataFrame via data= plus column names via x=, y=, hue=, size=, style=, letting seaborn handle grouping, aggregation and legends automatically. Wide-format data (one column per category) works for a few functions but usually needs reshaping with pandas.melt() first.

import pandas as pd

wide = pd.DataFrame({"year": [2022, 2023], "apples": [10, 14], "pears": [7, 9]})

# reshape to tidy/long format before handing it to seaborn
tidy = wide.melt(id_vars="year", var_name="fruit", value_name="count")
print(tidy)
#    year   fruit  count
# 0  2022  apples     10
# 1  2023  apples     14
# 2  2022   pears      7
# 3  2023   pears      9

🏗️ Figure-level vs axes-level functions

Seaborn has two families of plotting functions. Axes-level functions (scatterplot, lineplot, barplot, boxplot, histplot, heatmap, ...) draw onto a single Matplotlib Axes and accept an ax= argument, so they compose naturally with plt.subplots(). Figure-level functions (relplot, catplot, displot, lmplot, pairplot) manage their own Figure, return a grid object (FacetGrid or similar), and can build multi-panel "small multiples" with col=/row= faceting in one call — but they cannot be dropped into an existing subplot grid. Knowing which family a function belongs to explains almost every "why won't ax= work here" confusion beginners hit.

Function familyExamplesReturnsCan use ax=Can facet with col/row
Axes-levelscatterplot, lineplot, barplot, boxplot, violinplot, histplot, kdeplot, heatmap, regplotmatplotlib AxesYesNo
Figure-levelrelplot, catplot, displot, lmplot, pairplot, jointplotFacetGrid / PairGrid / JointGridNoYes (relplot, catplot, displot, lmplot)
Many figure-level functions are thin wrappers: relplot dispatches to scatterplot/lineplot, and catplot dispatches to barplot/boxplot/stripplot/etc. via its kind= argument.
If you only need one plot and want tight control, prefer the axes-level function. If you need small multiples split by a categorical column, reach for the figure-level version.

Module 2 — Getting Started

import seaborn · load_dataset · set_theme · first plot

▼

📦 Install, import, and built-in datasets

Install with pip install seaborn (it pulls in Matplotlib, NumPy and pandas as dependencies). By convention it is imported as sns — a nod to the TV character Samuel Norman Seaborn. Seaborn ships several small, well-known datasets through sns.load_dataset(name), which downloads (and caches) a CSV from seaborn's data repository and returns a tidy pandas DataFrame. These are ideal for practicing since they are already clean and long-format.

import seaborn as sns
import matplotlib.pyplot as plt

print(sns.__version__)

tips = sns.load_dataset("tips")
print(tips.shape)
print(tips.head())
#    total_bill   tip     sex smoker  day    time  size
# 0       16.99  1.01  Female     No  Sun  Dinner     2
# 1       10.34  1.66    Male     No  Sun  Dinner     3

🎨 Your first plot and sns.set_theme

A single call to sns.set_theme() switches every subsequent plot (seaborn or plain Matplotlib) from Matplotlib's default look to seaborn's cleaner style: light grid, muted colors, better default fonts. Most seaborn plotting functions share the same basic signature: data=<DataFrame>, then column names as strings for x=, y=, and optionally hue= for color grouping.

sns.set_theme(style="whitegrid")

sns.scatterplot(data=tips, x="total_bill", y="tip", hue="time")
plt.title("Tip amount vs. total bill")
plt.show()
sns.load_dataset requires internet access on first use (results are cached locally afterward in ~/seaborn-data). In offline environments, load your own CSV with pandas.read_csv instead — seaborn functions work identically on any tidy DataFrame.

🔍 Get a feel for a dataset before plotting

Before choosing a plot, inspect the DataFrame: df.info() for dtypes and missing values, df.describe() for numeric summaries, df["col"].unique() or value_counts() for categorical columns. This tells you which columns are continuous (good for x/y in relational or distribution plots) and which are categorical (good for hue, col, or the categorical-plot family).

print(tips.info())
print(tips["day"].value_counts())
print(tips.describe(include="number"))

Module 3 — Relational Plots

scatterplot · lineplot · relplot · hue/size/style/col/row

▼

🔗 scatterplot and lineplot

scatterplot shows the relationship between two continuous variables as points, one per observation — ideal for spotting correlation, clusters or outliers. lineplot connects points along x, and by default aggregates repeated x values: if several rows share the same x, it plots the mean and shades a 95% confidence interval band around it automatically, without you writing any aggregation code.

flights = sns.load_dataset("flights")

sns.scatterplot(data=tips, x="total_bill", y="tip", hue="smoker", style="time")
plt.show()

sns.lineplot(data=flights, x="year", y="passengers")  # auto mean + CI band across months
plt.show()

🪄 relplot: the figure-level relational function

relplot is the figure-level entry point for relational data; kind="scatter" (default) dispatches to scatterplot, kind="line" dispatches to lineplot. Beyond hue (color), it supports size (marker/line size mapped to a variable) and style (marker/dash style mapped to a variable) — letting you encode up to four variables (x, y, hue, size or style) in a single panel.

sns.relplot(
    data=tips, x="total_bill", y="tip",
    hue="day", size="size", style="time", kind="scatter"
)
plt.show()

🧩 Faceting with col and row

Figure-level functions can split data into a grid of small subplots using col= and/or row=, one panel per category — far faster than manually looping and creating subplots. col_wrap= wraps a long row of facets onto multiple lines.

sns.relplot(
    data=tips, x="total_bill", y="tip",
    hue="smoker", col="time", row="sex", kind="scatter"
)
plt.show()

sns.relplot(data=tips, x="total_bill", y="tip", col="day", col_wrap=2, kind="scatter")
plt.show()
Use lineplot (not scatterplot) for time-ordered or sequential data — it sorts by x by default and its automatic confidence band is one of seaborn's most useful built-in statistics.

🎤 One-Line Interview Answerscatterplot and lineplot are axes-level relational functions; relplot is their figure-level counterpart and adds col/row faceting plus size/style encodings in one call.

Module 4 — Categorical Plots: Comparisons

barplot · countplot · pointplot · Automatic CIs

▼

📊 barplot: comparing a statistic across categories

barplot shows a summary statistic (the mean, by default) of a numeric variable for each category, with a black error bar showing the bootstrapped 95% confidence interval — computed automatically, no manual groupby().mean() required. Change the statistic with estimator= (e.g. estimator="median" or any function) and the interval with errorbar= (e.g. errorbar="sd" for standard deviation, or errorbar=None to hide it).

sns.barplot(data=tips, x="day", y="total_bill", hue="sex", estimator="mean", errorbar="ci")
plt.show()

🔢 countplot: counting observations per category

countplot is barplot's simpler cousin: it just counts rows per category (like a histogram for categorical data) rather than summarizing a separate numeric column. It only needs x= or y=, not both.

sns.countplot(data=tips, x="day", hue="smoker")
plt.show()

📍 pointplot and reading built-in error bars

pointplot plots the same category-level statistic as barplot but as connected points instead of bars — this makes trends across an ordered categorical axis (e.g. days of the week, or experiment conditions) much easier to compare visually, since the eye tracks the line rather than comparing bar heights.

sns.pointplot(data=tips, x="day", y="total_bill", hue="sex", errorbar="ci", capsize=0.1)
plt.show()
Result
CategoryMean total_bill95% CI (approx.)
Thur17.6815.2 – 20.1
Fri17.1513.8 – 20.6

A bar's height is not the data's full story — two groups can have the same mean bar height with very different spreads. Pair barplot/pointplot with a distribution-revealing plot (Module 5) before concluding groups "look the same."

Module 5 — Categorical Plots: Distributions

boxplot · violinplot · stripplot · swarmplot

▼

📦 boxplot: quartiles and outliers

boxplot draws the five-number summary per category: median line, interquartile-range (IQR) box, whiskers to 1.5×IQR, and individual points beyond that flagged as outliers. It is compact and great for comparing spread and skew across many categories at once, but it hides multimodal shapes — two separate humps in the data collapse into one box.

sns.boxplot(data=tips, x="day", y="total_bill", hue="smoker")
plt.show()

🎻 violinplot: seeing the full distribution shape

violinplot mirrors a kernel density estimate (KDE) on each side of the category axis, so it reveals multimodality, skew, and where values actually concentrate — information a boxplot's five numbers cannot show. split=True with a two-level hue overlays both halves of the violin for a direct shape comparison without doubling the number of violins.

sns.violinplot(data=tips, x="day", y="total_bill", hue="smoker", split=True, inner="quartile")
plt.show()

⚫ stripplot and swarmplot: every individual point

stripplot plots every observation as a dot along the category axis, with light jitter to reduce overlap — honest about sample size but points can still overlap heavily. swarmplot solves overlap by algorithmically offsetting points so none collide, giving a true "beeswarm" view of the distribution, but it becomes slow and cluttered on large datasets (thousands of points). Both are often layered on top of a boxplot or violinplot for the best of both views.

sns.boxplot(data=tips, x="day", y="total_bill", color="lightgray")
sns.swarmplot(data=tips, x="day", y="total_bill", hue="smoker", size=4)
plt.show()

Module 6 — Distribution Plots

histplot · kdeplot · ecdfplot · displot

▼

📊 histplot: binned frequency counts

histplot draws a classic histogram: values binned along x, bar height showing frequency (or density, with stat="density"). hue= draws overlapping or stacked histograms per group (multiple="stack" or "dodge"), and kde=True overlays a smoothed density curve on top of the bars.

penguins = sns.load_dataset("penguins")

sns.histplot(data=penguins, x="flipper_length_mm", hue="species", multiple="stack", bins=20)
plt.show()

🌊 kdeplot and ecdfplot: smooth and cumulative views

kdeplot draws a Kernel Density Estimate — a smooth curve approximating the underlying probability density, avoiding the bin-width sensitivity of histograms. ecdfplot draws the empirical cumulative distribution function: for every x, the fraction of data at or below it — useful for directly comparing distributions and reading off percentiles, with no binning or smoothing choices at all.

sns.kdeplot(data=penguins, x="flipper_length_mm", hue="species", fill=True, common_norm=False)
plt.show()

sns.ecdfplot(data=penguins, x="flipper_length_mm", hue="species")
plt.show()

🧩 displot: the figure-level distribution function, and comparing groups

displot is the figure-level wrapper, with kind="hist" (default), "kde", or "ecdf", and it supports col=/row= faceting just like relplot. For comparing a distribution across many groups, prefer either overlaying with hue + kdeplot/ecdfplot (shapes stay comparable) or faceting with displot(..., col="species") (one clean panel per group, no overlap at all).

sns.displot(data=penguins, x="bill_length_mm", col="species", kind="hist", kde=True)
plt.show()
Histogram shape is sensitive to bins/binwidth — always try a couple of settings before drawing conclusions about shape (e.g. "bimodal") from a single histogram.

  1. Plot histplot and kdeplot of penguins["body_mass_g"] side by side and compare what each emphasizes.
  2. Use ecdfplot with hue="species" and read off the approximate median flipper length for each species from the curves.
🎤 One-Line Interview Answerhistplot bins and counts, kdeplot smooths into a density curve, ecdfplot shows the cumulative fraction with no binning, and displot is their shared figure-level wrapper that also facets with col/row.

Module 7 — Regression Plots

regplot · lmplot · Fitted line · Confidence band

▼

📈 regplot: scatter plus a fitted trend line

regplot draws a scatterplot and fits (by default) a linear regression line through the points, shading a 95% confidence interval band around the fit. It accepts order= for polynomial fits, logistic=True for a logistic fit on a binary y, and lowess=True for a non-parametric local fit.

sns.regplot(data=tips, x="total_bill", y="tip", ci=95, line_kws={"color": "crimson"})
plt.show()

🪄 lmplot: figure-level regression with facets

lmplot is the figure-level counterpart; it fits a separate regression per hue group (or per col/row facet), which makes it easy to check whether a relationship holds consistently across subgroups or differs between them (e.g. smokers vs. non-smokers).

sns.lmplot(data=tips, x="total_bill", y="tip", hue="smoker", col="time")
plt.show()

⚠️ Correlation, causation, and overfitting the fit

A fitted line and a tight confidence band describe the sample's linear trend — they do not prove causation, and a high-order polynomial (order=5) can hug noisy data closely while generalizing poorly. Always look at the underlying scatter, not just the line, and prefer the simplest order that visibly fits before reaching for a more flexible curve.

# compare a straight line to an overfit high-order polynomial on the same data
sns.regplot(data=tips, x="total_bill", y="tip", order=1, scatter_kws={"alpha": 0.4})
plt.show()
regplot is axes-level (works with ax=); lmplot is figure-level (facets with col/row, no ax=) — the same split pattern seen in every function pair in this material.

🏋️ Practice Questions

  1. Fit a linear regplot of tip vs total_bill and state, in one sentence, what the shaded band represents.
  2. Use lmplot with hue="smoker" to check whether the tip/bill relationship differs between smokers and non-smokers.
🎤 One-Line Interview Answerregplot fits and visualizes one regression with a confidence band on a single axes; lmplot is its figure-level version, fitting separate lines per hue group or facet to compare trends across subsets.

Module 8 — Heatmaps & Correlation Matrices

heatmap · annot · Correlation matrix · Diverging colormaps

▼

🔥 heatmap basics and annotating cells

heatmap colors a 2D grid of values (a pandas DataFrame or NumPy array) by magnitude — ideal for matrices, pivot tables, or any grid of numbers where color communicates scale faster than reading digits. annot=True writes each value inside its cell; fmt= controls number formatting (e.g. ".1f"); cbar=True (default) draws the color-scale legend.

flights_wide = sns.load_dataset("flights").pivot(index="month", columns="year", values="passengers")

sns.heatmap(flights_wide, annot=True, fmt="d", cmap="YlGnBu", linewidths=0.5)
plt.show()

🧮 Visualizing a correlation matrix

A very common use is plotting df.corr() — the pairwise Pearson correlation between every numeric column — as a heatmap, instantly surfacing strongly related variables. Masking the upper triangle (since the matrix is symmetric and the diagonal is always 1) reduces visual clutter.

import numpy as np

numeric = tips.select_dtypes("number")
corr = numeric.corr()

mask = np.triu(np.ones_like(corr, dtype=bool))  # hide the redundant upper triangle
sns.heatmap(corr, mask=mask, annot=True, fmt=".2f", cmap="coolwarm", vmin=-1, vmax=1)
plt.show()

🎨 Choosing diverging colormaps for signed data

When values are signed and centered at a meaningful zero (like correlation, ranging -1 to 1, or a percentage change), use a diverging colormap ("coolwarm", "RdBu_r", "vlag") so negative and positive values read as visually distinct colors on either side of a neutral midpoint. Reserve sequential colormaps ("viridis", "YlGnBu", "Blues") for unsigned, low-to-high data like raw counts. Always pass vmin=/vmax= (or center=0) for diverging maps so zero is guaranteed to land on the neutral color regardless of the data's actual min/max.

The default Matplotlib colormap "jet" is not perceptually uniform and can visually exaggerate or hide patterns — seaborn's defaults ("rocket", "viridis", "coolwarm") are chosen to avoid this.

Module 9 — Pair Plots & Pair Grids

pairplot · PairGrid · Multivariate EDA

▼

🧩 pairplot: one call, every pairwise relationship

pairplot builds a grid of scatterplots for every pair of numeric columns in a DataFrame, with histograms (or KDEs) of each variable along the diagonal — an extremely fast way to scan a whole dataset for correlations, clusters and outliers before deciding what to investigate further. hue= colors points by a categorical column, instantly showing whether groups separate on any variable pair.

sns.pairplot(penguins, hue="species", diag_kind="kde", corner=True)
plt.show()

🛠️ Customizing with PairGrid

PairGrid is the lower-level object pairplot is built on. It sets up the grid of axes without choosing what to draw in them, so you call .map_diag(), .map_offdiag() (or .map_upper()/.map_lower()) to place different plot types on different parts of the grid — e.g. KDEs on the diagonal, scatter on the lower triangle, and a correlation value as text on the upper triangle.

g = sns.PairGrid(penguins.dropna(), hue="species")
g.map_diag(sns.kdeplot)
g.map_lower(sns.scatterplot)
g.map_upper(sns.kdeplot, fill=True, alpha=0.3)
g.add_legend()
plt.show()
corner=True on pairplot draws only the lower triangle, halving the number of (redundant, mirrored) panels for a cleaner figure.
pairplot is the right first move on almost any new tidy dataset with a handful of numeric columns — it is often the single most useful "explore everything" command in seaborn.

🏋️ Practice Questions

  1. Run sns.pairplot(penguins, hue="species") and identify which pair of variables separates the species most cleanly.
  2. Build a custom PairGrid with scatter plots below the diagonal and KDE plots above it.
🎤 One-Line Interview Answerpairplot auto-generates every pairwise scatter plus per-variable diagonal distributions for quick multivariate EDA; PairGrid is the underlying, fully customizable object when you need different plot types on different parts of the grid.

Module 10 — Facet Grids

FacetGrid · Small multiples · .map()

▼

🧱 FacetGrid: small multiples from one dataset

FacetGrid is the general-purpose engine behind every col=/row= facet seen so far (relplot, catplot, displot, lmplot all build one internally). You construct it directly when you want full control: sns.FacetGrid(data, col=..., row=..., hue=...) creates an empty grid of subplots, one per combination of category levels, ready for a plotting function to be mapped onto every panel at once.

g = sns.FacetGrid(tips, col="time", row="smoker", hue="sex", margin_titles=True)
g.map(sns.scatterplot, "total_bill", "tip")
g.add_legend()
plt.show()

🗺️ Mapping a plotting function across subsets

.map(func, *args) calls func once per facet, automatically passing only that facet's slice of the data — func can be any plotting function that accepts positional x, y arrays, including plain Matplotlib functions like plt.hist or plt.scatter, not only seaborn ones. .map_dataframe(func, ...) instead passes the facet's DataFrame directly, which is needed for functions (seaborn's own) that expect data= plus column-name strings.

g = sns.FacetGrid(tips, col="day", col_wrap=2, height=3)
g.map_dataframe(sns.histplot, x="total_bill", hue="smoker", kde=True)
g.set_axis_labels("Total bill ($)", "Count")
g.set_titles(col_template="{col_name}")
plt.show()
Reach for a figure-level function (relplot, catplot, displot) first — they build the right FacetGrid for you. Build a FacetGrid by hand only when you need a plot type, combination, or layout those wrappers do not directly support.

🏋️ Practice Questions

  1. Build a FacetGrid faceted by day, mapping sns.histplot of total_bill onto each panel.
  2. Explain the difference between .map() and .map_dataframe() and when each is required.
🎤 One-Line Interview AnswerFacetGrid is the small-multiples engine every figure-level seaborn function uses internally; you build one directly, then .map() or .map_dataframe() a plotting function onto every facet at once.

Module 11 — Styling, Themes & Color Palettes

set_style · set_context · color_palette · Qualitative/Sequential/Diverging

▼

🎭 set_style and set_context

sns.set_style() controls the overall look: "white", "dark", "whitegrid", "darkgrid", "ticks" — switching background, gridlines and spines together. sns.set_context() scales font sizes, line widths and marker sizes for the output medium: "paper" (smallest), "notebook" (default), "talk", "poster" (largest) — so the same plotting code produces appropriately sized text whether it is headed for a dense paper figure or a projector slide.

sns.set_style("ticks")
sns.set_context("talk")

sns.scatterplot(data=tips, x="total_bill", y="tip", hue="day")
plt.show()

🎨 Palette families: qualitative, sequential, diverging

Choosing the right palette *type* for the data matters more than choosing a pretty one. Qualitative palettes ("deep", "Set2", "husl") use visually distinct hues with no implied order — for unordered categories like day or species. Sequential palettes ("viridis", "Blues", "rocket") progress light-to-dark — for ordered or continuous data like counts or magnitude. Diverging palettes ("coolwarm", "RdBu_r", "vlag") have two hues meeting at a neutral midpoint — for signed data centered at a meaningful zero, as in Module 8.

🖌️ color_palette in depth

sns.color_palette(name, n_colors) returns the actual list of RGB colors a palette name resolves to, which you can preview with sns.color_palette(name).as_hex() or pass straight into palette= on any plotting function. sns.set_palette() sets one globally for the session, the same way set_theme(palette=...) can.

palette = sns.color_palette("Set2", n_colors=4)
print(palette.as_hex())

sns.boxplot(data=tips, x="day", y="tip", hue="day", palette="Set2", legend=False)
plt.show()
Never use a diverging or rainbow palette to encode unordered categories — it visually implies an ordering or extremes that are not in the data, misleading readers.

  2. Pick an appropriate palette type (qualitative, sequential or diverging) for: (a) country names, (b) population counts, (c) year-over-year percentage change — and justify each choice.

Module 12 — Combining Seaborn with Matplotlib

ax= argument · plt customization · Mixed figures

▼

🔧 Passing ax= to place seaborn in a matplotlib figure

Every axes-level seaborn function accepts ax=, letting you place it into a Matplotlib Figure/Axes layout you built yourself with plt.subplots() — essential for mixing seaborn plots with raw Matplotlib ones, or laying out panels that figure-level functions cannot express (seaborn's own facets are always identical plot types; manual subplots can mix different plot types freely).

fig, axes = plt.subplots(1, 2, figsize=(10, 4))

sns.histplot(data=tips, x="total_bill", ax=axes[0])
sns.boxplot(data=tips, x="day", y="tip", ax=axes[1])

fig.suptitle("Bill distribution and tips by day")
plt.tight_layout()
plt.show()

✏️ Customizing a seaborn plot afterward with matplotlib calls

Because a seaborn axes-level call returns (or receives) a normal Matplotlib Axes, every familiar Matplotlib customization still applies afterward: ax.set_title(), ax.set_xlabel(), ax.axhline(), ax.legend(), tick formatting, annotations. For figure-level functions, the returned grid object exposes .fig (the Matplotlib Figure) and .axes (its array of Axes) for the same kind of post-hoc tweaking.

ax = sns.scatterplot(data=tips, x="total_bill", y="tip", hue="time")
ax.set_title("Tip vs. Bill, colored by meal time")
ax.axhline(tips["tip"].mean(), color="gray", linestyle="--", label="mean tip")
ax.legend(title="Meal")
plt.show()

g = sns.relplot(data=tips, x="total_bill", y="tip", col="time")
g.fig.suptitle("Faceted by meal time", y=1.05)
for ax in g.axes.flat:
    ax.axvline(20, color="red", linestyle=":")
plt.show()
When a figure-level function's facets almost do what you want but you need one extra annotation on every panel, loop over g.axes.flat (or g.axes_dict when col/row are both used) rather than abandoning the figure-level call.

Module 13 — A Real EDA Workflow with Seaborn

Distributions → Relationships → Correlations → Categorical comparisons

▼

🔍 Steps 1-2: understand individual distributions, then relationships

A disciplined seaborn EDA pass on a new dataset (here, tips) moves from simple to complex. First, look at each numeric variable alone with histplot/kdeplot to spot skew, outliers or odd clustering. Second, look at pairs of numeric variables with pairplot or targeted scatterplot/relplot calls to spot linear or nonlinear relationships.

tips = sns.load_dataset("tips")

# step 1: individual distributions
sns.histplot(data=tips, x="total_bill", kde=True)
plt.show()

# step 2: pairwise relationships, colored by a key category
sns.pairplot(tips, vars=["total_bill", "tip", "size"], hue="time")
plt.show()

🧮 Steps 3-4: correlations, then categorical comparisons

Third, quantify linear relationships across all numeric columns at once with a heatmap of df.corr(). Fourth, bring the categorical columns in: compare the key numeric outcome (tip, or a derived tip_pct) across each categorical column with boxplot/violinplot/barplot, which is usually where the business-relevant findings surface ("do smokers tip differently by day?").

# step 3: correlation matrix
sns.heatmap(tips.select_dtypes("number").corr(), annot=True, cmap="coolwarm", center=0)
plt.show()

# step 4: categorical comparison on a derived metric
tips["tip_pct"] = tips["tip"] / tips["total_bill"] * 100
sns.boxplot(data=tips, x="day", y="tip_pct", hue="smoker")
plt.show()

sns.catplot(data=tips, x="day", y="tip_pct", hue="smoker", col="time", kind="violin")
plt.show()
This distribution → relationship → correlation → categorical-comparison order is not arbitrary: each step's findings inform what to look for in the next — a skewed distribution in step 1 explains an odd-looking scatter in step 2, which a strong correlation in step 3 then confirms numerically, before step 4 checks whether that pattern holds (or breaks) across subgroups.

Module 14 — Common Mistakes & Best Practices

Long vs wide · Overplotting · Misleading aggregation · Wrong plot choice

▼

🔀 Long vs wide data confusion

The single most common seaborn stumbling block is passing wide-format data (one column per category) where a function expects long/tidy format (one row per observation, a column naming the category). Symptoms include functions silently plotting the wrong thing, or needing awkward column-by-column calls. The fix is almost always df.melt() before plotting, as shown in Module 1.

# wrong shape for most seaborn calls: one column per product
wide = pd.DataFrame({"month": ["Jan", "Feb"], "A": [10, 12], "B": [7, 9]})

# fix: reshape first
tidy = wide.melt(id_vars="month", var_name="product", value_name="sales")
sns.barplot(data=tidy, x="month", y="sales", hue="product")
plt.show()

🐌 Overplotting with large datasets

scatterplot and swarmplot on tens of thousands of points become a solid, uninformative blob (or, for swarmplot, painfully slow to render). Mitigations: lower alpha= for transparency so density shows through overlaps, downsample with df.sample(n=...), switch to histplot/kdeplot/hexbin-style density plots that summarize rather than plot every point, or use sns.displot(..., kind="hist") with 2D binning via x=/y= together.

# instead of a scatter blob on 50k rows, show density
sns.histplot(data=big_df, x="col_a", y="col_b", bins=50, cbar=True)
plt.show()

📉 Misleading aggregation and picking the wrong categorical plot

barplot's default mean can hide a bimodal or skewed group — two groups with identical mean bars can have completely different shapes underneath. Always sanity-check a barplot/pointplot finding against a boxplot or violinplot of the same data before trusting it. Likewise, picking boxplot when the real story is *how many* modes a distribution has (better shown by violinplot or kdeplot), or picking swarmplot on data far too large for it to render cleanly, are both avoidable with a quick glance at Module 5's comparison table.

A clean-looking bar chart is not proof of a clean underlying distribution — bars only show one summary statistic plus an interval, never shape.

Module 15 — Interview Questions

Seaborn concepts, trade-offs, and real interview phrasing

▼

Q: What is seaborn, and how does it relate to matplotlib?

Seaborn is a statistical visualization library built directly on top of matplotlib — every seaborn plot is rendered through matplotlib's Figure and Axes objects underneath. It adds a higher-level API that understands tidy pandas DataFrames, computes common statistics automatically (means, confidence intervals, KDEs, regression fits), and ships better-looking defaults out of the box. The trade-off is less low-level control than raw matplotlib offers directly, but seaborn plots remain fully matplotlib objects, so you can always drop down and customize with matplotlib calls afterward.

Q: What is the difference between figure-level and axes-level functions?

Axes-level functions (scatterplot, boxplot, heatmap, histplot, etc.) draw onto a single matplotlib Axes, accept an ax= argument, and compose with plt.subplots(). Figure-level functions (relplot, catplot, displot, lmplot, pairplot) manage their own Figure and can facet into a grid of panels with col=/row=, but cannot be placed into an existing subplot layout via ax=. I pick axes-level when I need one plot inside a custom layout, and figure-level when I need automatic small multiples across a categorical variable.

Q: When would you use relplot over scatterplot directly?

I use relplot when I need faceting — splitting the same relationship into multiple panels by a categorical column via col= or row= — or when I want to switch between scatter and line behavior with a single kind= argument. For a single, standalone relational plot with no faceting, scatterplot or lineplot directly is simpler and composes with an existing matplotlib figure via ax=, which relplot cannot do.

Q: What is the difference between boxplot and violinplot, and when would you pick one over the other?

A boxplot shows the five-number summary — median, IQR box, whiskers, and flagged outliers — which is compact and scales well across many categories. A violinplot mirrors a kernel density estimate on each side of the axis, revealing the full distribution shape, including multimodal or skewed data that a boxplot's five numbers would hide. I default to boxplot for a first compact scan across many groups, then switch to violinplot once I suspect a group's distribution shape itself is the interesting finding, or when I need to split=True a hue to directly compare two subgroup shapes.

Q: How does seaborn compute confidence intervals and aggregation automatically, and what should you watch out for?

Functions like barplot, pointplot and lineplot aggregate repeated x values to a summary statistic — the mean by default, configurable via estimator= — and draw a bootstrapped confidence interval (errorbar="ci", 95% by default) as an error bar or shaded band, with no manual groupby() required. The caveat is that this automatic aggregation can hide the underlying distribution's spread or shape entirely; a bar chart with identical heights can sit on top of very different underlying distributions, so I pair it with a boxplot or violinplot before drawing conclusions from a bar chart alone.

Q: What is a FacetGrid, and how does it relate to functions like relplot and catplot?

FacetGrid is the underlying small-multiples engine: given col=/row=/hue=, it builds a grid of matplotlib Axes, one per combination of category levels. relplot, catplot, displot and lmplot all build a FacetGrid internally and then map their corresponding plotting function onto every panel — they're convenience wrappers over it. I build a FacetGrid directly only when I need a plot type or combination those wrappers don't directly support, using .map() or .map_dataframe() to apply a custom function across every facet.

Q: How do you choose a color palette for a seaborn plot?

The choice depends on what the color variable represents, not aesthetics alone. Qualitative palettes (deep, Set2, husl) suit unordered categories since no hue implies order. Sequential palettes (viridis, rocket, Blues) suit ordered or continuous unsigned data, going light to dark with magnitude. Diverging palettes (coolwarm, RdBu_r) suit signed data centered at a meaningful zero, like correlation or percent change, with vmin/vmax/center set explicitly so zero lands on the neutral color. Using the wrong family — say, a diverging palette on unordered categories — visually implies an ordering or extreme that isn't actually in the data.

Q: What does pairplot do, and when would you reach for PairGrid instead?

pairplot automatically builds a grid of scatterplots for every pair of numeric columns in a DataFrame, with each variable's own distribution along the diagonal, making it one of the fastest ways to scan a new dataset for correlations, clusters, and outliers. I reach for PairGrid directly when I need different plot types on different parts of the grid — for example KDEs on the diagonal, scatter below it, and a different summary above it — since PairGrid only lays out the axes and lets me .map_diag()/.map_lower()/.map_upper() whatever functions I choose.

Q: What is "tidy" or "long-format" data, and why does seaborn care?

Tidy data has one row per observation and one column per variable — for example a sales table with date, region and sales columns, rather than one sales column per region. Almost every seaborn function is designed around this shape: you pass data=df plus column names to x=, y=, hue=, and seaborn handles grouping and aggregation internally. Wide-format data, with one column per category, usually needs pandas.melt() to reshape into long format first; skipping this step is the most common reason a seaborn call "doesn't work as expected."

Q: How would you visualize a correlation matrix, and what should you be careful about?

I'd compute df.corr() and pass it to sns.heatmap() with annot=True for readable values, a diverging colormap like coolwarm, and vmin=-1, vmax=1, center=0 so zero correlation always maps to the neutral color regardless of the actual data range. Since the matrix is symmetric with a diagonal of 1s, I often mask the upper triangle with numpy to cut visual clutter. I'm careful to remember correlation only captures linear relationships — two variables can be strongly, non-linearly related and still show a near-zero correlation value on the heatmap.

Q: How do histplot, kdeplot and ecdfplot differ, and when would you choose each?

histplot bins the data and shows frequency or density per bin, which is intuitive but sensitive to bin width choices. kdeplot smooths that into a continuous density curve, avoiding bin-width artifacts but introducing its own smoothing-bandwidth choice. ecdfplot shows the cumulative fraction of data at or below each x value, with no binning or smoothing decisions at all, which makes it the most honest choice for directly comparing distributions or reading off percentiles. I typically start with histplot for a first look, add kde=True or switch to kdeplot once I want a cleaner shape comparison across groups, and use ecdfplot when I specifically need percentile-style comparisons.

Q: How do you combine a seaborn plot with custom matplotlib code?

Every axes-level seaborn function accepts ax= and returns the matplotlib Axes it drew on, so I can create my own fig, axes = plt.subplots(...) layout, pass each panel's ax= to a seaborn call, and then call ordinary matplotlib methods on that same Axes afterward — ax.set_title(), ax.axhline(), ax.legend(), and so on. For figure-level functions, the returned grid object exposes .fig and .axes for the same kind of post-hoc customization across every facet in a loop.

Q: What's a mistake you've seen (or would watch for) when someone uses seaborn for the first time?

A frequent one is treating barplot's default mean-plus-confidence-interval as the whole story about a group, without ever looking at a boxplot or violinplot of the same data — two groups can show identical bars while having completely different underlying shapes. Another is overplotting: calling scatterplot or swarmplot on tens of thousands of rows, which renders as an uninformative blob or runs very slowly; the fix is lowering alpha, downsampling, or switching to a density-based plot like histplot with 2D binning.
