@module m1 | 🧭 | 1 · Introduction | Module 1 — Introduction to Java | JVM · JDK · Bytecode · Editions · Platform independence
@topic ☕ What is Java?
Java is a statically typed, class-based language designed to run on many platforms. `javac` compiles source into bytecode; a Java Virtual Machine (JVM) executes that bytecode for its operating system and processor. The JVM can interpret bytecode and compile frequently used paths to native machine code with a JIT compiler.
@topic 🧰 JDK, JRE and JVM
The **JDK** is the development kit: compiler, tools and runtime. The **JVM** executes bytecode. A **JRE** is the runtime concept and may be bundled differently by vendors; modern JDK distributions are commonly installed directly. Java SE is the standard platform, Jakarta EE adds enterprise specifications, and Java ME targets constrained devices. Java is used for servers, Android applications, financial systems, tools and large enterprise software.
@code text
Java source (.java) → javac → bytecode (.class) → JVM → machine instructions
@end
@table
Language | Typical distinction
Java | Static types, JVM bytecode, automatic memory management
C | Native compilation, manual memory management, no JVM
C++ | Native compilation, multiple paradigms, fine-grained resource control
Python | Dynamic typing, interpreted/bytecode runtime, concise scripting
@end
@info Java is not automatically portable in every situation: native libraries, filesystem assumptions and runtime versions can affect portability. Bytecode plus a compatible JVM provides the portability model.
@practice
1. Explain what `javac`, bytecode and the JVM each do.
2. Name one Java SE application and one Jakarta EE use case.
@interview Java compiles source into platform-neutral bytecode, which a platform-specific JVM verifies and executes, often with JIT compilation.

@module m3 | 👋 | 3 · First Program | Module 3 — Your First Java Program | Class · main · System.out · Compile · Run
@topic 👋 Read every part of the program
A class groups code. `public` makes the class accessible; `static` lets the launcher call `main` without constructing an object; `void` means it returns no value. `String[] args` receives command-line arguments. `System.out` is the standard output stream and `println` prints a line.
@code java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
        System.out.printf("Arguments: %d%n", args.length);
    }
}
@end
@info Save this as `Main.java`, then run `javac Main.java` followed by `java Main`. `%n` is a platform-correct line separator for formatted output.
@practice
1. Change the program to print your name and city on separate lines.
2. Pass two words on the command line and print `args[0]` and `args[1]`.
@interview The Java launcher starts at `public static void main(String[] args)`; the method receives command-line strings and returns no value.

@module m4 | 🎛️ | 4 · Types | Module 4 — Variables & Primitive Data Types | Primitives · References · final · Casting · Scope
@topic 🎛️ The eight primitive types
Java primitives are `byte`, `short`, `int`, `long`, `float`, `double`, `char` and `boolean`. Variables of class types hold references to objects. A local variable must be assigned before use; fields receive default values. `char` is a UTF-16 code unit, not necessarily a full Unicode character.
@code java
int age = 25;
double salary = 35000.50;
char grade = 'A';
boolean active = true;
long population = 8_000_000_000L;
float ratio = 0.75F;
@end
@topic 🔒 Declaration, scope, constants and conversion
Declare with a type, assign with `=`, and use `final` for a value assigned once. Scope is where a name is visible; local variables live within their block, while object fields exist with their object. Widening conversions are often implicit; narrowing conversions need a cast and may lose data. Integer division truncates toward zero.
@code java
final double TAX_RATE = 0.08;
int whole = (int) 3.9;       // 3: narrowing truncates
int quotient = 7 / 2;        // 3: integer division
double precise = 7 / 2.0;    // 3.5
@end
@practice
1. Choose types for a person's age, a bank balance, an initial and an active flag.
2. Explain the difference between a local variable and a field.
@interview Java has eight primitives; reference variables point to objects, and explicit casts are required for potentially lossy narrowing conversions.

@module m5 | ➗ | 5 · Operators | Module 5 — Java Operators | Arithmetic · Comparison · Boolean · Bitwise · Ternary
@topic ➗ Work with values and conditions
Arithmetic operators include `+ - * / %`; comparisons include `> < >= <= == !=`; boolean logic uses `&& || !`. Assignment operators combine updates such as `+=`. `++` and `--` change an integer by one. For objects, `==` compares references; use `equals` for value comparison.
@topic 🧮 Bits, shifts and conditional expressions
Bitwise `& | ^ ~` operate on integer bits; `<<`, `>>` and unsigned right shift `>>>` move bits. `&&` and `||` short-circuit, while `&` and `|` can evaluate both boolean sides. The ternary operator chooses one of two expressions.
@code java
int a = 10, b = 3;
int max = a > b ? a : b;
int remainder = a % b;
int unsignedShift = -8 >>> 1;
boolean eligible = a > 0 && b != 0;
@end
@warn Do not use `==` to compare the contents of ordinary Strings. Use `equals` or `equalsIgnoreCase`.
@practice
1. Write a condition that accepts a score from 0 through 100.
2. Calculate a maximum with the ternary operator and explain `&&` short-circuiting.
@interview Java operators follow precedence rules; use parentheses to make intent explicit, `&&` / `||` short-circuit, and `==` on references tests identity.

@module m6 | 📥 | 6 · Input & Output | Module 6 — Console Input & Output | print · printf · Scanner · BufferedReader · Arguments
@topic 📥 Print and read values
Use `print` without a newline, `println` with a newline and `printf` for formatted output. `Scanner` is beginner-friendly and tokenizes input. After `nextInt`, a following `nextLine` may consume the remaining newline; call `nextLine` once to clear it before reading a full line.
@code java
import java.util.Scanner;

Scanner input = new Scanner(System.in);
System.out.print("Enter age: ");
int age = input.nextInt();
input.nextLine(); // consume the newline left by nextInt
System.out.print("Enter name: ");
String name = input.nextLine();
System.out.printf("%s is %d%n", name, age);
@end
@topic ⚡ Buffered input
For large input, `BufferedReader` with `InputStreamReader` avoids some Scanner parsing overhead; parse numeric strings explicitly. Command-line arguments are available in `args`. Close resources you open, preferably with try-with-resources.
@practice
1. Read an integer and then a full line containing spaces.
2. Print a decimal with two digits after the decimal point.
@interview Use `System.out` for console output; `Scanner` is convenient for parsed input, while buffered readers suit fast text input.

@module m7 | 🔀 | 7 · Conditions | Module 7 — Conditional Statements & Switch | if · else · switch · Switch expressions · yield
@topic 🔀 Branch on a condition
`if`, `else if` and `else` choose a branch based on a boolean expression. Put braces around branch bodies even when they contain one statement; this avoids mistakes as code grows.
@code java
int score = 86;
if (score >= 90) {
    System.out.println("A");
} else if (score >= 75) {
    System.out.println("B");
} else {
    System.out.println("Keep practicing");
}
@end
@topic 🎯 Use switch for a set of alternatives
Traditional `switch` uses `case`, `break` and `default`; forgetting `break` can fall through. Modern switch expressions use arrow labels and return a value. A multi-statement arm uses `yield` to provide that value.
@code java
int day = 6;
String kind = switch (day) {
    case 6, 7 -> "weekend";
    case 1, 2, 3, 4, 5 -> "weekday";
    default -> throw new IllegalArgumentException("Invalid day");
};
@end
@practice
1. Assign a letter grade with an if/else-if chain.
2. Use a switch expression to map a month number to a season.
@interview Use if/else for ranges and compound conditions; switch is useful for discrete alternatives, and switch expressions return a value without accidental fall-through.

@module m8 | 🔁 | 8 · Loops | Module 8 — Loops & Control Flow | for · while · do-while · Enhanced for · break · continue
@topic 🔁 Repeat work
Use `for` when initialization, condition and update belong together; `while` when repetition depends on a changing condition; `do-while` when the body must execute at least once. Enhanced `for` traverses array or collection values when an index is unnecessary.
@code java
int[] numbers = {10, 20, 30};
for (int number : numbers) {
    System.out.println(number);
}
for (int i = 1; i <= 3; i++) {
    System.out.println(i);
}
@end
@topic ⏹️ Control a loop
`break` exits the nearest loop or switch; `continue` skips to the next iteration; `return` exits the current method. Avoid changing a collection while enhanced-for iterating it unless using the iterator's supported removal operation.
@practice
1. Sum the values in an array with an enhanced for loop.
2. Find the first negative number and stop searching.
@interview Choose a loop based on when its condition is checked and whether an index is needed; break exits and continue skips an iteration.

@module m9 | 🧩 | 9 · Methods | Module 9 — Methods & Overloading | Parameters · Returns · static · Varargs · Pass-by-value
@topic 🧩 Define reusable behavior
A method has a return type, name, parameters and body. An argument is the value passed at a call site. `void` means no result is returned. Java passes every argument by value, including a copy of an object reference. Overloading uses the same method name with different parameter lists; return type alone cannot distinguish overloads.
@code java
static int add(int left, int right) {
    return left + right;
}

static int sum(int... values) {
    int total = 0;
    for (int value : values) total += value;
    return total;
}
@end
@topic 🔧 Static and instance methods
A static method belongs to a class and has no `this`; an instance method works with a particular object's state. Keep methods focused, name parameters clearly and return values instead of printing when callers need to reuse the result.
@practice
1. Write overloaded `area` methods for a square and rectangle.
2. Create a varargs method that returns the largest supplied integer.
@interview Java overloads are selected from method name and parameter types at compile time; Java is always pass-by-value, even when the value is an object reference.

@module m10 | 📚 | 10 · Arrays | Module 10 — Arrays | Declaration · Traversal · Search · Sort · 2D arrays
@topic 📚 Store a fixed-size sequence
An array has a fixed length and contains values of one component type. Indices run from 0 to `length - 1`; `length` is a field, not a method. Arrays of objects initially contain `null`; primitive arrays contain zero-like defaults.
@code java
import java.util.Arrays;

int[] numbers = {10, 20, 30, 40};
Arrays.sort(numbers);
int position = Arrays.binarySearch(numbers, 30); // sort first
System.out.println(numbers.length + " " + position);
@end
@topic 🧮 Multidimensional arrays
Java multidimensional arrays are arrays of arrays, so rows can have different lengths. Use nested loops for matrix traversal; verify dimensions before element-wise operations.
@code java
int[][] matrix = {{1, 2}, {3, 4}};
for (int[] row : matrix) {
    for (int value : row) System.out.print(value + " ");
    System.out.println();
}
@end
@practice
1. Find the largest number in an array and report its index.
2. Add two compatible 2D matrices with nested loops.
@interview Arrays have fixed length, zero-based indexing and one component type; Java's multidimensional arrays are nested arrays, not a special matrix primitive.

@module m11 | 📝 | 11 · Strings | Module 11 — String & Immutability | Pool · equals · substring · split · Search · Transform
@topic 📝 Strings are immutable
A `String` cannot be changed after creation; operations return another String. The string pool can reuse equal literals, but application logic must not depend on object identity. `==` compares references; `equals` compares characters.
@code java
String language = "Java";
String sameText = new String("Java");
System.out.println(language == sameText);      // false: different references
System.out.println(language.equals(sameText)); // true: same text
@end
@topic 🔎 Useful String methods
Common methods include `length`, `charAt`, `substring`, `equalsIgnoreCase`, `compareTo`, `contains`, `startsWith`, `endsWith`, `indexOf`, `replace`, `split`, `trim`, `toUpperCase` and `toLowerCase`. `length()` counts UTF-16 code units, which may differ from user-perceived characters.
@code java
String text = "  Learn Java  ".trim();
String[] words = text.split(" ");
System.out.println(text.toUpperCase());
System.out.println(text.substring(0, 5));
@end
@practice
1. Compare two separately constructed strings by value.
2. Count occurrences of a word after splitting a sentence.
@interview String is immutable and may be pooled; compare content with `equals`, not `==`, and remember String methods return new values.

@module m12 | 🪢 | 12 · Mutable Text | Module 12 — StringBuilder & StringBuffer | append · insert · delete · reverse · Thread safety
@topic 🪢 Build text efficiently
Repeated `+` in a loop can create many temporary Strings. `StringBuilder` is a mutable character sequence suited to local construction; `StringBuffer` provides synchronized methods for legacy shared-use cases and is usually unnecessary for local work.
@code java
StringBuilder message = new StringBuilder("Java");
message.append(" is").append(" useful");
message.insert(0, "Learn ");
message.replace(0, 5, "Study");
message.delete(5, 6);
System.out.println(message.reverse());
@end
@table
Type | Mutable? | Thread-safe by default? | Typical use
String | No | Yes, because immutable | Text values
StringBuilder | Yes | No | Efficient local text construction
StringBuffer | Yes | Synchronized methods | Legacy shared mutable text
@end
@practice
1. Build a comma-separated list with StringBuilder.
2. Reverse a word without changing the original String.
@interview Use String for values, StringBuilder for efficient mutable construction, and StringBuffer only when its synchronization is specifically needed.

@module m13 | 🏛️ | 13 · OOP Basics | Module 13 — Classes, Objects & Constructors | State · Behavior · this · static
@topic 🏛️ Model a concept with a class
A class defines fields (state) and methods (behavior); an object is one instance. A constructor initializes a new object and has the class name. `this` refers to the current object and disambiguates fields from parameters. A static field is shared by the class, not copied per instance.
@code java
class Student {
    String name;
    int age;

    Student(String name, int age) {
        this.name = name;
        this.age = age;
    }

    void display() {
        System.out.println(name + " (" + age + ")");
    }
}
@end
@topic 🧪 Create and use an object
Use `new` to construct an object; local variables hold references to it. Encapsulation (next module) protects its state from invalid changes.
@code java
Student learner = new Student("Asha", 20);
learner.display();
@end
@practice
1. Create a `Book` class with title, author and a display method.
2. Add a static field that counts how many objects are created.
@interview A class defines object state and behavior; each object has its own instance fields while static fields belong to the class.

@module m14 | 🔐 | 14 · Encapsulation | Module 14 — Encapsulation & Access Control | Private fields · Validation · Getters · Setters
@topic 🔐 Protect object invariants
Encapsulation hides representation and exposes intentional operations. Make fields private and validate changes through methods; not every field needs a setter. A setter should preserve the class's valid-state rules.
@code java
class Student {
    private int age;

    public int getAge() {
        return age;
    }

    public void setAge(int age) {
        if (age < 0) throw new IllegalArgumentException("age must be nonnegative");
        this.age = age;
    }
}
@end
@practice
1. Add a private balance field with a deposit method that rejects negative amounts.
2. Explain why a public field weakens validation.
@interview Encapsulation hides mutable representation and protects invariants by allowing state changes only through controlled methods.

@module m15 | 🧬 | 15 · Inheritance | Module 15 — Inheritance & super | extends · Single · Multilevel · Hierarchical
@topic 🧬 Reuse and specialize behavior
A subclass uses `extends` to inherit accessible members and may add or override behavior. Java supports single inheritance of classes; multiple behavior contracts are expressed with interfaces. Prefer composition when a type is not truly a specialized form of another.
@code java
class Animal {
    void eat() { System.out.println("Eating"); }
}

class Dog extends Animal {
    @Override
    void eat() { System.out.println("Dog eating"); }
}
@end
@topic 🔝 Call the parent implementation
`super` accesses a superclass constructor or member. A constructor's `super(...)` call must be first; Java inserts a no-argument superclass constructor call if none is written and one is available.
@practice
1. Model `Vehicle` and `Car` using inheritance, then explain the is-a relationship.
2. Give an example better modeled with composition.
@interview Java class inheritance is single; subclasses use `extends` and `super`, while interfaces provide multiple behavioral contracts.

@module m16 | 🎭 | 16 · Polymorphism | Module 16 — Overloading & Overriding | Compile-time · Runtime · Dynamic dispatch
@topic 🎭 One name, different behavior
Overloading selects among same-name methods using their parameter lists at compile time. Overriding replaces an inherited instance method; runtime dispatch chooses the implementation based on the actual object. Static methods are hidden, not overridden.
@code java
class Shape {
    double area() { return 0; }
}
class Circle extends Shape {
    private final double radius;
    Circle(double radius) { this.radius = radius; }
    @Override double area() { return Math.PI * radius * radius; }
}
Shape shape = new Circle(2);
System.out.println(shape.area()); // Circle implementation
@end
@practice
1. Create a base `Payment` type and two overriding payment implementations.
2. Explain overloading versus overriding and when dispatch occurs.
@interview Overloading is compile-time selection by parameters; overriding enables runtime polymorphism through dynamic dispatch on an object's actual class.

@module m17 | 🫥 | 17 · Abstraction | Module 17 — Abstract Classes & Methods | Abstract contract · Shared implementation
@topic 🫥 Represent incomplete common behavior
An abstract class cannot be instantiated directly. It may contain fields, constructors, abstract methods without bodies and concrete methods shared by subclasses. A concrete subclass must implement all inherited abstract methods.
@code java
abstract class Animal {
    abstract void sound();
    void eat() { System.out.println("Eating"); }
}
class Cat extends Animal {
    @Override void sound() { System.out.println("Meow"); }
}
@end
@practice
1. Create an abstract `Shape` with an abstract `area` method and a concrete description method.
2. When is an abstract class more useful than an interface?
@interview An abstract class defines a shared base with common state or implementation and may require concrete subclasses to implement abstract methods.

@module m18 | 🔌 | 18 · Interfaces | Module 18 — Interfaces & Functional Contracts | implements · Default · Static · Private methods
@topic 🔌 Program against a contract
An interface specifies behavior that unrelated classes can implement. A class may implement many interfaces. Interface fields are constants; modern interfaces can also define default and static methods, and private helpers for their own method implementations.
@code java
interface Payable {
    double amountDue();
    default boolean isFree() { return amountDue() == 0; }
    static String currency() { return "USD"; }
}
class Invoice implements Payable {
    public double amountDue() { return 49.99; }
}
@end
@topic 🧩 Functional interface
A functional interface has one abstract method and can be implemented with a lambda. `@FunctionalInterface` asks the compiler to verify the contract.
@practice
1. Define a `Printable` interface and implement it in two unrelated classes.
2. Add a default method and explain its purpose.
@interview Interfaces express contracts and allow a class to implement multiple types; default and static methods add behavior without requiring every implementer to define it.

@module m19 | 🪪 | 19 · Modifiers | Module 19 — Access Modifiers | private · package-private · protected · public
@topic 🪪 Control visibility
`private` is visible inside the declaring top-level class (including nested-class access rules); package-private means no modifier and is visible in the package; `protected` is visible in the package and to subclasses under Java's protected-access rules; `public` is broadly accessible when its enclosing types are accessible. Top-level classes can be public or package-private, not private/protected.
@table
Modifier | Same class | Same package | Subclass outside package | Unrelated package
`private` | Yes | No | No | No
package-private | Yes | Yes | No | No
`protected` | Yes | Yes | Yes, through subclass rules | No
`public` | Yes | Yes | Yes | Yes
@end
@practice
1. Choose visibility for an internal field, a package helper and a public API method.
2. Why is protected access outside a package more nuanced than public access?
@interview Use the least visibility that supports the API; protected members are accessible to subclasses subject to Java's cross-package rules.

@module m20 | 📦 | 20 · Packages | Module 20 — Packages & Imports | package · import · Standard library · Namespaces
@topic 📦 Organize code by package
A package groups related types and prevents naming collisions. A `package` declaration appears first in a source file; folders conventionally mirror the package name. `import` allows a type to be referenced by its simple name but does not copy code into the class.
@code java
package com.example.app;

import java.time.LocalDate;
import java.util.ArrayList;

class Reminder {
    LocalDate dueDate;
    ArrayList<String> labels = new ArrayList<>();
}
@end
@topic 🧰 Know common packages
`java.lang` is implicitly available; `java.util` provides collections and utilities; `java.io` and `java.nio.file` handle I/O; `java.time` provides modern dates; `java.sql` supports JDBC. Prefer explicit imports over wildcard imports in shared code.

@module m21 | 🪞 | 21 · Object | Module 21 — Object, equals & hashCode | toString · equals · hashCode · getClass · clone
@topic 🪞 The root class and value identity
Every class ultimately extends `Object`. Override `toString` for useful diagnostics and `equals` for logical value equality. If two objects are equal, their `hashCode` values must match; unequal objects may share a hash. This contract matters in HashMap and HashSet.
@code java
@Override
public boolean equals(Object other) {
    if (this == other) return true;
    if (!(other instanceof Student student)) return false;
    return id == student.id;
}

@Override
public int hashCode() {
    return Integer.hashCode(id);
}
@end
@topic 🧬 Other Object methods
`getClass` reports runtime class. `clone` has awkward shallow-copy semantics and is not the usual preferred copying API; use a copy constructor or factory with clear semantics. Records can generate value-oriented methods for simple immutable data carriers.
@practice
1. Implement `equals` and `hashCode` for an immutable value type.
2. Explain why equal objects must have equal hash codes.
@interview Override `equals` and `hashCode` together for value equality; equal objects must produce equal hash codes for hash-based collections to work correctly.

@module m22 | 🏗️ | 22 · Constructors | Module 22 — Constructors & Chaining | Default · No-arg · Parameters · this() · super()
@topic 🏗️ Initialize valid objects
A constructor has the class name and no return type. Java supplies a default no-argument constructor only when no constructor is declared. Constructors can be overloaded; `this(...)` calls another constructor in the same class, and `super(...)` calls a superclass constructor. Either constructor call must be the first statement.
@code java
class User {
    private final String name;
    private final int age;

    User(String name) {
        this(name, 0);
    }

    User(String name, int age) {
        this.name = name;
        this.age = age;
    }
}
@end
@practice
1. Add a validating constructor to a `BankAccount` class.
2. Explain when the compiler supplies a default constructor.
@interview Constructors establish an object's initial valid state; `this()` chains within the class and `super()` selects a superclass constructor.

@module m23 | ⚠️ | 23 · Exceptions | Module 23 — Exception Handling | Throwable · Checked · Runtime · try · catch · finally
@topic ⚠️ Understand the hierarchy
`Throwable` has two main branches: `Error` for serious runtime/environment problems and `Exception` for conditions applications may handle. Checked exceptions must be caught or declared; unchecked `RuntimeException` subclasses need not be declared. Avoid catching `Throwable` or swallowing exceptions.
@code java
try {
    int result = 10 / 0;
} catch (ArithmeticException exception) {
    System.out.println("Cannot divide by zero");
} finally {
    System.out.println("Cleanup belongs here when needed");
}
@end
@topic 🧯 Choose the right mechanism
`throw` raises an exception; `throws` declares possible checked exceptions. Try-with-resources automatically closes `AutoCloseable` resources. Catch an exception where you can add context, recover, translate it or report it meaningfully.
@practice
1. Handle invalid numeric input without hiding unrelated programming errors.
2. Name one checked and one unchecked exception.
@interview Checked exceptions must be handled or declared; unchecked exceptions are RuntimeException subclasses, while Error usually represents conditions applications should not recover from.

@module m24 | 🧪 | 24 · Custom Exceptions | Module 24 — Custom Exceptions & Propagation | Domain errors · Checked · Unchecked · Causes
@topic 🧪 Define meaningful domain failures
Create a custom exception when callers benefit from a specific failure type. Extend `Exception` for a checked condition the caller is expected to handle, or `RuntimeException` for an unchecked programming/domain failure. Include a useful message and preserve the original cause when translating.
@code java
class InvalidAgeException extends Exception {
    InvalidAgeException(String message) {
        super(message);
    }
}

static void register(int age) throws InvalidAgeException {
    if (age < 18) throw new InvalidAgeException("Must be an adult");
}
@end
@topic 🔗 Propagation
An exception propagates up the call stack until a matching handler is found. Declare checked exceptions in a method's `throws` clause or handle them. Do not use exceptions for ordinary branching.
@practice
1. Define an `InsufficientFundsException` and decide whether it is checked.
2. Wrap an I/O exception with a domain-specific message while preserving its cause.
@interview Custom exceptions name domain failures; exception propagation unwinds callers until a handler can recover, translate or report the problem.

@module m25 | 🧺 | 25 · Collections Intro | Module 25 — Collections Framework Overview | List · Set · Queue · Map · Generics
@topic 🧺 Pick a collection by behavior
`Collection` is the root interface for many element collections. `List` keeps a sequence and allows duplicates; `Set` enforces uniqueness; `Queue` models retrieval order. `Map` stores key-value pairs and is part of the framework but does not extend `Collection`.
@code java
List<String> names = new ArrayList<>();
Set<String> uniqueNames = new HashSet<>();
Queue<String> tasks = new ArrayDeque<>();
Map<String, Integer> scores = new HashMap<>();
@end
@info Prefer interface types in variable declarations and choose an implementation for ordering, lookup, concurrency and performance requirements.
@practice
1. Choose a collection for ordered duplicate names, unique tags and ID-to-score lookup.
2. Explain why Map is not a subtype of Collection.
@interview Choose List for ordered duplicates, Set for uniqueness, Queue for retrieval policy and Map for key-value lookup.

@module m26 | 📃 | 26 · List | Module 26 — List Implementations | ArrayList · LinkedList · Vector · Stack
@topic 📃 Use common List operations
A List is ordered, indexed and permits duplicates. `ArrayList` is the usual default for fast indexed reads and append-at-end. `LinkedList` supports efficient operations at its ends but indexed access is slow. `Vector` and `Stack` are legacy synchronized types; prefer `ArrayList` and `Deque` for new code.

@end
@topic 🧹 More operations
`add`, `remove`, `get`, `set`, `contains`, `size`, `clear` and `isEmpty` cover common workflows. Removing by integer from `List<Integer>` can select an index; use `Integer.valueOf(value)` to remove a matching object value.

@topic 🔷 Enforce uniqueness
A Set rejects duplicates as defined by equality. `HashSet` offers efficient average lookup without ordering guarantees; `LinkedHashSet` preserves insertion order; `TreeSet` sorts values and typically needs comparable elements or a Comparator.

Set<String> tags = new LinkedHashSet<>();

@topic 🧮 Hashing and ordering
Hash-based sets depend on correct `equals` and `hashCode`. Tree-based sets depend on comparison consistency. Mutating fields used by equality or sorting while an object is stored can break lookup behavior.

@topic 🗺️ Store key-value associations
A Map has unique keys and maps each key to a value. `HashMap` is the usual general-purpose implementation; `LinkedHashMap` preserves encounter order; `TreeMap` sorts keys. `Hashtable` is legacy; use a concurrent map when thread-safe access is required.

@module m29 | 🚦 | 29 · Queue & Deque | Module 29 — Queues, PriorityQueue & Deque | offer · poll · peek · FIFO · Priority
@topic 🚦 Model pending work
A Queue typically retrieves in FIFO order. `offer` adds, `poll` retrieves or returns null when empty, and `peek` inspects the head without removing it. `add`, `remove` and `element` may throw when an operation cannot be completed.
@code java

jobs.offer("report");
System.out.println(jobs.peek());
System.out.println(jobs.poll());
@end
@topic 🏁 Priority and both ends
`PriorityQueue` retrieves by priority ordering, not insertion order. `Deque` supports both ends and can act as a queue or stack; `ArrayDeque` is a good default and disallows null elements.

@topic 🔁 Traverse safely
`Iterator` exposes `hasNext`, `next` and optional `remove`. `ListIterator` adds backwards traversal, indices and supported add/set operations for lists. Enhanced for is simpler for read-only traversal.

@module m31 | 🔢 | 31 · Sorting Objects | Module 31 — Comparable & Comparator | Natural order · Custom order · thenComparing
@topic 🔢 Define natural ordering
`Comparable<T>` defines an object's natural ordering through `compareTo`. Return a negative value, zero or positive value to indicate less, equal or greater ordering. Comparison should be consistent and transitive.
@code java
record Student(String name, int score) implements Comparable<Student> {
    public int compareTo(Student other) {
        return Integer.compare(score, other.score);

}
@end
@topic 🧭 Supply alternate orderings
`Comparator<T>` defines an external ordering and can be composed with `comparing` and `thenComparing`. Prefer comparator factories to subtraction-based comparison, which can overflow.
@code java

    .comparing(Student::name)
    .thenComparingInt(Student::score);

@end
@practice

2. Explain when Comparable is suitable and when Comparator is more flexible.
@interview Comparable defines a type's natural ordering; Comparator supplies reusable alternative orderings that can be composed.

@module m32 | 🧬 | 32 · Generics | Module 32 — Generics, Bounds & Wildcards | Type parameters · PECS · Type safety · Erasure
@topic 🧬 Parameterize reusable code
Generics express types at compile time, preventing many casts and type errors. Use type parameters on classes, interfaces and methods. Java generics use type erasure at runtime and cannot directly use primitive type arguments; use wrapper classes such as `Integer`.
@code java
class Box<T> {
    private T value;
    void set(T value) { this.value = value; }
    T get() { return value; }
}
Box<String> box = new Box<>();
box.set("safe text");
@end
@topic 🎚️ Bounds and wildcard variance
`<T extends Number>` bounds a type parameter. `? extends T` is useful as a producer of T; `? super T` is useful as a consumer. The mnemonic **PECS** means Producer Extends, Consumer Super. A wildcard collection is not generally safe to add arbitrary values to.
@code java
static double total(List<? extends Number> values) {
    double result = 0;
    for (Number value : values) result += value.doubleValue();
    return result;
}
@end
@practice
1. Write a generic method that returns the first element of a list.
2. Explain PECS and why `List<Integer>` is not a `List<Number>`.
@interview Generics provide compile-time type safety; use bounded type parameters and the PECS rule to design flexible APIs.

@topic 🔌 Standard behavior contracts
`Predicate<T>` tests and returns boolean; `Function<T,R>` transforms; `Consumer<T>` accepts a value and returns no result; `Supplier<T>` creates or supplies a value. `UnaryOperator<T>` and `BinaryOperator<T>` specialize functions where inputs and output share a type. `@FunctionalInterface` documents and validates a single abstract method.

@module m35 | 🌊 | 35 · Streams | Module 35 — Stream API | filter · map · flatMap · collect · reduce
@topic 🌊 Transform data declaratively
A Stream pipeline has a source, lazy intermediate operations and a terminal operation. `filter` keeps matching values; `map` transforms each; `flatMap` maps and flattens nested streams. Streams are consumed once and do not store data.
@code java
List<Integer> numbers = List.of(4, 12, 7, 20);
List<Integer> result = numbers.stream()
    .filter(number -> number > 10)
    .map(number -> number * 2)
    .toList();
System.out.println(result);
@end
@topic 🧮 Terminal operations
Common operations include `sorted`, `distinct`, `limit`, `skip`, `forEach`, `collect`, `reduce`, `count`, `min` and `max`. Use `collect` to build results; use `reduce` for combining values. Avoid side effects in parallel pipelines and use parallel streams only after measurement.
@code java
int total = numbers.stream().reduce(0, Integer::sum);
long count = numbers.stream().filter(number -> number > 10).count();
@end
@warn Do not modify the stream's source from inside the pipeline. Prefer clear loops when a stream becomes harder to understand than the transformation.
@practice
1. Filter even numbers, square them, sort and collect the result.
2. Flatten a list of lists with `flatMap`.
@interview Streams lazily compose transformations and run them at a terminal operation; they are single-use pipelines, not collections.

@module m43 | 🔒 | 43 · Synchronization | Module 43 — Thread Safety & Synchronization | Race · synchronized · volatile · Deadlock
@topic 🔒 Coordinate shared mutable state
A race condition occurs when outcomes depend on unsynchronized timing. A critical section protects shared invariants. `synchronized` provides mutual exclusion and visibility for the same monitor. Prefer immutability or message passing where practical.
@code java

    synchronized void increment() { value++; }
    synchronized int get() { return value; }
}
@end
@topic ⚡ Visibility and deadlocks
`volatile` makes reads/writes visible across threads but does not make compound operations such as `count++` atomic. Use atomics or locks for compound updates. Deadlock can arise from inconsistent lock ordering; starvation occurs when a thread cannot get enough access to resources.

@module m47 | 💳 | 47 · Transactions | Module 47 — JDBC Transactions & ACID | Commit · Rollback · Isolation · Atomic work
@topic 💳 Group updates atomically
A transaction groups related operations so either all succeed or the database rolls them back. ACID means atomicity, consistency, isolation and durability. Disable auto-commit, perform the unit of work, commit on success and rollback on failure.
@code java
connection.setAutoCommit(false);
try {
    debit(connection, fromId, amount);
    credit(connection, toId, amount);
    connection.commit();
} catch (SQLException exception) {
    connection.rollback();
    throw exception;
} finally {
    connection.setAutoCommit(true);
}
@end
@topic 🧭 Isolation and boundaries
Isolation levels trade concurrency against anomalies such as dirty reads or non-repeatable reads. Keep transactions short; do not wait on network calls while holding database locks. In Spring, transaction boundaries are commonly managed with `@Transactional`.
@practice
1. Explain why a money transfer must debit and credit in one transaction.
2. Name the four ACID properties.
@interview Transactions preserve a database unit of work; commit on success, rollback on failure and choose an isolation level appropriate to consistency needs.

@code java
int binarySearch(int[] sorted, int target) {
    int low = 0, high = sorted.length - 1;
    while (low <= high) {
        int mid = low + (high - low) / 2;
        if (sorted[mid] == target) return mid;
        if (sorted[mid] < target) low = mid + 1;
        else high = mid - 1;
    }
    return -1;
}
@end

@module m76 | 🎤 | Interview Prep | Java Interview Questions & Answers | JVM · OOP · Collections · Exceptions · Generics · Concurrency
@topic Q: What is the difference between the JDK, JRE, and JVM?
The JVM executes Java bytecode. The JRE is the runtime components needed to run Java applications, conceptually including the JVM and libraries. The JDK includes development tools such as the compiler and debugger along with runtime components; modern distributions may not package a separate JRE installer.
@topic Q: How does Java code run on different platforms?
The Java compiler translates source code into platform-independent bytecode. A compatible JVM for the target platform loads and executes that bytecode, with implementation details such as just-in-time compilation varying by JVM.
@topic Q: What is the difference between primitive and reference types?
Primitive types hold values such as integers, floating-point numbers, booleans, and characters. Reference variables refer to objects; they can be `null` and support object behavior defined by their class.
@topic Q: Why is `String` immutable in Java?
An immutable string cannot change after construction, which makes sharing and caching safer and supports predictable hashing. Operations that appear to modify a string create a new string instead.
@topic Q: What is the contract between `equals` and `hashCode`?
If two objects are equal according to `equals`, they must return the same `hashCode`. Unequal objects may have the same hash code; overriding one method generally requires overriding the other consistently.
@topic Q: What is the difference between method overloading and overriding?
Overloading uses the same method name with different parameter lists and is resolved at compile time. Overriding supplies a compatible implementation in a subtype and uses runtime dispatch for instance methods.
@topic Q: What does `static` mean for a field or method?
A static member belongs to the class rather than to a particular instance. Static methods do not have an instance `this` and cannot directly access instance members without an object reference.
@topic Q: What does `final` mean for a variable, method, and class?
A final variable can be assigned only once; a final method cannot be overridden; and a final class cannot be subclassed. A final reference does not make the referenced object's state immutable.
@topic Q: When would you use an interface instead of an abstract class?
Use an interface to describe a capability or contract that unrelated classes can implement. Use an abstract class when related subclasses need shared instance state or common implementation; a class can extend only one class but implement multiple interfaces.
@topic Q: What is encapsulation?
Encapsulation groups state and behavior behind a deliberate API. Restricting direct access to internal state lets a class enforce invariants and change its implementation without breaking callers.
@topic Q: How do `ArrayList` and `LinkedList` differ?
`ArrayList` provides efficient indexed access and is a common default for lists. `LinkedList` has linear indexed access and can insert or remove at its ends efficiently; the right choice depends on actual operation patterns and measurements.
@topic Q: How does `HashMap` use `hashCode` and `equals`?
It uses a key's hash code to locate a bucket and equality checks to distinguish keys within that bucket. Correct, stable implementations of both methods are important while an object is used as a key.
@topic Q: What is the difference between checked and unchecked exceptions?
Checked exceptions must be caught or declared by the method signature. Unchecked exceptions extend `RuntimeException` and do not have that compile-time requirement; use them for programming errors or conditions callers are not required to handle by declaration.
@topic Q: What does try-with-resources do?
It closes resources that implement `AutoCloseable` when the block exits, including when an exception occurs. It is the preferred pattern for files, streams, and similar resources that need deterministic cleanup.
@topic Q: What is type erasure in Java generics?
Java generics are primarily enforced by the compiler; generic type information is generally erased from ordinary runtime types. This supports compatibility with older bytecode but means some parameterized type details are unavailable for runtime checks.
@topic Q: What does `volatile` guarantee, and what does it not guarantee?
Volatile reads and writes provide visibility and ordering guarantees for that variable between threads. It does not make compound operations such as incrementing a counter atomic; use synchronization or an atomic class for those operations.
@topic Q: What does `synchronized` provide?
It provides mutual exclusion for code guarded by the same monitor and establishes visibility guarantees when a thread releases and another acquires that monitor. Keep critical sections small and avoid inconsistent lock ordering.
@topic Q: Why use an `ExecutorService` instead of creating a thread for every task?
An executor manages task submission and thread reuse, helping control concurrency and resource usage. It also provides lifecycle management and result handling through `Future` and related APIs.
@topic Q: What is dependency injection?
Dependency injection supplies a class's collaborators from the outside rather than having the class construct them directly. It reduces coupling and makes dependencies easier to replace in tests or different application configurations.
@topic Q: When does a Java Stream operation execute?
Intermediate operations such as `map` and `filter` are lazy and describe a pipeline. A terminal operation such as `collect`, `toList`, or `forEach` triggers traversal and evaluation.
@topic Q: What is the purpose of `Optional`?
`Optional<T>` represents a value that may be absent and encourages callers to handle that absence explicitly. It is commonly used for return values; it is generally not intended as a replacement for every nullable field or parameter.
