@module m1 | 🧭 | 1 · Intro | Module 1 — Introduction to CSS | What is CSS · Syntax · Three ways to add CSS · Comments · First stylesheet
@topic 📜 What is CSS?
CSS (**Cascading Style Sheets**) controls how HTML looks: colours, fonts, spacing, layout, and animation. HTML gives the structure; CSS gives the presentation.
@table
Aspect | Detail
Proposed by | Håkon Wium Lie, 1994
Maintained by | W3C (World Wide Web Consortium)
Versions | CSS1 (1996), CSS2 (1998), then "CSS3" split into separate modules that keep evolving
File extension | `.css`
@end
@topic ✏️ CSS Syntax
@code css
/* selector   { property: value; } */
h1 {
  color: green;          /* declaration = property + value */
  font-size: 32px;
}
@end
@table
Part | Meaning | Example
Selector | Which elements to style | `h1`, `.card`, `#menu`
Property | What to change | `color`, `margin`
Value | The new setting | `green`, `16px`
Declaration | One property–value pair ending with `;` | `color: green;`
Rule | Selector + a block of declarations | `h1 { ... }`
@end
@topic 🔌 Three Ways to Add CSS
@code html
<!-- 1. Inline: one element (avoid) -->
<p style="color: red;">Inline</p>

<!-- 2. Internal: one page, inside <head> -->
<style>
  p { color: navy; }
</style>

<!-- 3. External: the whole site (best) -->
<link rel="stylesheet" href="css/style.css">
@end
@table
Method | Scope | Use for
Inline | One element | Quick tests only
Internal | One page | Demos and single pages
External | Every page that links it | Real projects: cached and reusable
@end
@topic 👋 Your First Stylesheet
@code css
/* css/style.css */
body {
  font-family: Arial, sans-serif;
  background: #f5f7f5;
  color: #222;
  margin: 0;
}
h1 { color: #15803d; }
p  { line-height: 1.6; }
@end
@practice
1. Create `index.html` and `css/style.css`, link them, and change the page's background and font.
2. Style the same paragraph with inline, internal and external CSS. Which one wins?
3. Label the selector, property, value and declaration in `a { color: blue; }`.
4. Why are external stylesheets preferred for real websites?
@interview CSS styles HTML using rules made of selectors and declarations (property: value); it can be inline, internal or external, and external stylesheets are best for real sites.

@module m2 | 🎯 | 2 · Selectors | Module 2 — Selectors | Element · Class · ID · Universal · Grouping · Combinators · Attribute selectors
@topic 🎯 Basic Selectors
@code css
p { color: #333; }             /* element: every <p> */
.card { padding: 16px; }        /* class: class="card" */
#header { height: 60px; }       /* id: id="header" (unique) */
* { box-sizing: border-box; }   /* universal: every element */
h1, h2, h3 { font-weight: 700; }/* grouping: several selectors, one rule */
@end
@topic 🔗 Combinators
@code css
nav a { color: white; }          /* descendant: any <a> inside nav */
ul > li { list-style: none; }    /* child: direct children only */
h2 + p { margin-top: 0; }        /* adjacent sibling: the <p> right after h2 */
h2 ~ p { color: gray; }          /* general sibling: every <p> after h2 */
@end
@table
Combinator | Name | Selects
`A B` | Descendant | B anywhere inside A
`A > B` | Child | B directly inside A
`A + B` | Adjacent sibling | The B immediately after A
`A ~ B` | General sibling | Every B after A (same parent)
@end
@topic 🏷️ Attribute Selectors
@code css
input[type="email"] { border-color: blue; }   /* exact value */
a[href^="https"]    { color: green; }         /* starts with */
a[href$=".pdf"]     { font-weight: bold; }    /* ends with */
img[alt*="logo"]    { width: 120px; }         /* contains */
[disabled]          { opacity: .5; }          /* attribute exists */
@end
@tip Style with **classes** most of the time. IDs are too specific to override easily, and element selectors are too broad.
@practice
1. Make all links inside `<nav>` white and all other links green.
2. Style only direct `<li>` children of a menu, not nested ones.
3. Give every link to a PDF a 📄 marker using an attribute selector (hint: combine with `::before` from Module 3).
4. Remove the top margin of every paragraph that comes right after a heading.
@interview Selectors choose which elements a rule styles: element, .class, #id, universal and attribute selectors, plus combinators for descendant (space), child (>), adjacent (+) and general sibling (~) relationships.

@module m3 | ✨ | 3 · Pseudo | Module 3 — Pseudo-classes & Pseudo-elements | :hover · :focus · :nth-child · :not · :has · ::before · ::after
@topic 🖱️ Pseudo-classes: States
@code css
a:hover   { text-decoration: underline; }    /* pointer over it */
a:visited { color: purple; }                  /* already visited */
button:active { transform: scale(.97); }      /* being clicked */
input:focus   { outline: 2px solid #15803d; } /* has keyboard focus */
input:focus-visible { outline-offset: 2px; }  /* focus from the keyboard */
input:invalid { border-color: red; }          /* fails validation */
input:disabled, input:checked { opacity: .8; }
@end
@topic 🔢 Pseudo-classes: Position and Logic
@code css
li:first-child   { font-weight: bold; }
li:last-child    { border-bottom: none; }
tr:nth-child(even) { background: #f3f4f6; }  /* 2, 4, 6 … */
li:nth-child(3n + 1) { color: green; }       /* 1, 4, 7 … */
p:not(.note)     { color: #333; }            /* every p except .note */
:is(h1, h2, h3) a { color: inherit; }        /* shorter grouping */
.card:has(img)   { padding: 0; }             /* parent that contains an img */
@end
@topic 🪄 Pseudo-elements
@code css
.price::before  { content: "₹"; }                     /* insert before content */
.required::after { content: " *"; color: red; }       /* insert after content */
p::first-letter { font-size: 2em; float: left; }      /* drop cap */
p::first-line   { font-weight: bold; }
input::placeholder { color: #9ca3af; }
::selection     { background: #bbf7d0; }              /* highlighted text */
@end
@table
Pseudo-class (one colon) | Pseudo-element (two colons)
Selects an element in a **state** or position | Styles a **part** of an element or adds content
`:hover`, `:focus`, `:nth-child()` | `::before`, `::after`, `::placeholder`
@end
@info `::before` and `::after` need the `content` property, even if it is empty: `content: "";`
@practice
1. Create a button that changes colour on hover and shrinks slightly while clicked.
2. Zebra-stripe a table using `:nth-child(even)`.
3. Add a red asterisk after every required form label with `::after`.
4. Highlight a form card with `:has(input:invalid)` when a field is wrong.
5. What is the difference between `:first-child` and `:first-of-type`?
@interview Pseudo-classes select elements in a state or position (:hover, :focus, :nth-child, :has), while pseudo-elements style part of an element or insert content (::before, ::after, ::placeholder).

@module m4 | ⚖️ | 4 · Cascade | Module 4 — Cascade, Specificity & Inheritance | Cascade order · Specificity · !important · Inheritance · inherit/initial/unset
@topic 🌊 The Cascade
When several rules target the same element, the browser picks the winner in this order:
1. **Importance** — `!important` declarations win
2. **Specificity** — the more specific selector wins
3. **Source order** — if equal, the rule written **last** wins
@topic 🧮 Specificity
@table
Selector | Specificity (id, class, element) | Example
Inline `style=""` | Beats all selectors | `<p style="color:red">`
ID | (1, 0, 0) | `#menu`
Class, attribute, pseudo-class | (0, 1, 0) | `.card`, `[type="text"]`, `:hover`
Element, pseudo-element | (0, 0, 1) | `p`, `::before`
Universal `*`, `:where()` | (0, 0, 0) | `*`
@end
@code css
p            { color: black; }   /* (0,0,1) */
.intro       { color: blue; }    /* (0,1,0)  wins over p */
#hero .intro { color: green; }   /* (1,1,0)  wins over .intro */
p            { color: red !important; }  /* beats everything above: avoid */
@end
@warn Avoid `!important`. It breaks the normal cascade and forces more `!important` later. Fix the selector instead.
@topic 👪 Inheritance
Some properties pass from parent to children automatically.
@table
Usually inherited | Not inherited
`color`, `font-family`, `font-size`, `line-height`, `text-align`, `visibility`, `cursor` | `margin`, `padding`, `border`, `background`, `width`, `height`, `display`, `position`
@end
@code css
body { font-family: Arial, sans-serif; color: #222; }  /* children inherit these */
button { font: inherit; }        /* force inheritance (buttons don't inherit fonts) */
.reset { color: initial; }       /* back to the property's default */
.plain { all: unset; }           /* remove every inherited and default style */
@end
@practice
1. Calculate the specificity of `nav ul li a:hover` and `#main .btn`.
2. Write two conflicting rules and make the second one win without `!important`.
3. Show that `color` is inherited by a child but `border` is not.
4. Why do form buttons often need `font: inherit`?
@interview The cascade decides which rule applies by importance, then specificity (id > class > element), then source order; some properties such as color and font are inherited by children.

@module m5 | 🌈 | 5 · Colors | Module 5 — Colors & Backgrounds | Named · Hex · RGB · HSL · Opacity · Backgrounds · Gradients
@topic 🌈 Colour Formats
@code css
.a { color: green; }                      /* named colour */
.b { color: #15803d; }                    /* hex: #RRGGBB */
.c { color: #15803d80; }                  /* hex with alpha (50%) */
.d { color: rgb(21 128 61); }             /* red green blue (0–255) */
.e { color: rgb(21 128 61 / 0.5); }       /* with transparency */
.f { color: hsl(142 72% 29%); }           /* hue saturation lightness */
.g { border: 2px solid currentColor; }    /* uses the element's text colour */
@end
@table
Format | Best for
Named | Quick demos (`red`, `teal`)
Hex | Copying brand colours from design tools
RGB | When you think in red/green/blue
HSL | Creating lighter/darker shades by changing lightness
@end
@info `opacity: 0.5` makes the **whole element** (and its children) see-through. `rgb(... / 0.5)` makes only that colour transparent.
@topic 🖼️ Backgrounds
@code css
.hero {
  background-color: #0f172a;
  background-image: url("images/hero.jpg");
  background-size: cover;          /* fill the box, crop if needed */
  background-position: center;
  background-repeat: no-repeat;
  background-attachment: fixed;    /* parallax-like effect */
}

/* Shorthand */
.banner { background: #111 url("bg.png") center / cover no-repeat; }
@end
@topic 🎨 Gradients
@code css
.linear { background: linear-gradient(135deg, #15803d, #10b981); }
.radial { background: radial-gradient(circle, #fef08a, #f59e0b); }
.conic  { background: conic-gradient(red, yellow, green, blue, red); }
.overlay {
  background: linear-gradient(rgb(0 0 0 / .5), rgb(0 0 0 / .5)), url("photo.jpg") center / cover;
}   /* dark overlay on an image: several backgrounds, first is on top */
@end
@practice
1. Write the same green colour in hex, RGB and HSL.
2. Create a full-screen hero section with a background image and a dark gradient overlay.
3. Make a button with a gradient background that changes direction on hover.
4. Explain the difference between `opacity: .5` and `background: rgb(0 0 0 / .5)`.
@interview CSS colours can be named, hex, rgb() or hsl() with optional transparency; backgrounds support images, size, position and linear, radial and conic gradients.

@module m6 | 📏 | 6 · Units | Module 6 — Units & Values | px · % · em · rem · vw/vh · ch · calc() · min() · max() · clamp()
@topic 📏 Absolute and Relative Units
@table
Unit | Relative to | Typical use
`px` | Fixed pixel | Borders, small fixed sizes
`%` | The parent's size | Widths inside a container
`em` | The element's font size (parent's, for font-size) | Padding that scales with text
`rem` | The root (`html`) font size, usually 16px | Font sizes and spacing everywhere
`vw` / `vh` | 1% of the viewport width / height | Full-screen sections
`dvh` | 1% of the dynamic viewport height | Mobile full-height (address bar aware)
`ch` | Width of the "0" character | Readable line length: `max-width: 65ch`
`fr` | A fraction of free space in Grid | Grid columns
@end
@code css
html { font-size: 100%; }         /* 16px, respects the user's settings */
h1   { font-size: 2.5rem; }       /* 40px */
.btn { padding: .5em 1em; }       /* grows with the button's font size */
.hero { min-height: 100dvh; }
.article { max-width: 65ch; }
@end
@tip Use `rem` for font sizes so the page respects the user's browser font setting.
@topic 🧮 Math Functions
@code css
.sidebar  { width: calc(100% - 250px); }          /* mix units */
.card     { width: min(100%, 400px); }            /* the smaller value */
.section  { padding: max(2rem, 5vw); }            /* the larger value */
h1        { font-size: clamp(1.8rem, 4vw, 3rem); }/* min, preferred, max */
@end
@practice
1. Set the root font size and size all headings with rem.
2. Make a section exactly the height of the screen on phones using `dvh`.
3. Create fluid heading sizes with `clamp()` that never go below 24px or above 48px.
4. Limit article text to a comfortable reading width with `ch`.
5. What is the difference between `em` and `rem`?
@interview px is fixed, % follows the parent, em follows the element's font size, rem follows the root font size, and vw/vh follow the viewport; calc(), min(), max() and clamp() compute flexible values.

@module m7 | 🔤 | 7 · Typography | Module 7 — Typography | Fonts · Web fonts · Size · Weight · Line height · Alignment · Decoration · Overflow
@topic 🔤 Font Properties
@code css
body {
  font-family: "Poppins", "Segoe UI", Arial, sans-serif;   /* font stack with fallbacks */
  font-size: 1rem;
  font-weight: 400;        /* 100–900; 400 normal, 700 bold */
  font-style: normal;      /* or italic */
  line-height: 1.6;        /* unitless: 1.6 × font size */
}
h1 { font: 700 2.5rem/1.2 "Poppins", sans-serif; }   /* shorthand */
@end
@topic 🌐 Web Fonts
@code html
<!-- Google Fonts in the <head> -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link href="https://fonts.googleapis.com/css2?family=Poppins:wght@400;600;700&display=swap" rel="stylesheet">
@end
@code css
/* Your own font file */
@font-face {
  font-family: "MyFont";
  src: url("fonts/myfont.woff2") format("woff2");
  font-weight: 400;
  font-display: swap;      /* show fallback text while loading */
}
@end
@topic 📝 Text Properties
@table
Property | Example | Effect
`text-align` | `center`, `justify` | Horizontal alignment
`text-transform` | `uppercase`, `capitalize` | Change letter case
`text-decoration` | `none`, `underline wavy red` | Lines on text
`letter-spacing` | `0.05em` | Space between letters
`word-spacing` | `4px` | Space between words
`text-indent` | `2em` | Indent the first line
`text-shadow` | `2px 2px 4px rgb(0 0 0 / .3)` | Shadow behind text
`white-space` | `nowrap`, `pre` | How spaces and line breaks behave
`word-break` / `overflow-wrap` | `break-word` | Break long words or URLs
@end
@topic ✂️ Truncating Text
@code css
.one-line {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;       /* "Long title that…" */
}
.three-lines {
  display: -webkit-box;
  -webkit-line-clamp: 3;         /* show at most 3 lines */
  -webkit-box-orient: vertical;
  overflow: hidden;
}
@end
@practice
1. Add a Google Font and use it for headings with a fallback stack.
2. Set comfortable body text: 1rem, line height 1.6, max width 65ch.
3. Make a card title that ends with "…" when it is too long.
4. Create an uppercase, letter-spaced label style.
5. Why is a unitless line-height recommended?
@interview Typography is controlled with font-family stacks, size, weight, line-height and text properties; web fonts load with Google Fonts or @font-face, and text-overflow: ellipsis truncates long text.

@module m8 | 📦 | 8 · Box Model | Module 8 — The Box Model | Content · Padding · Border · Margin · box-sizing · Margin collapse · Radius · Shadows
@topic 📦 Every Element is a Box
@code bash
┌──────────────── margin ────────────────┐
│  ┌──────────── border ─────────────┐   │
│  │  ┌───────── padding ─────────┐  │   │
│  │  │         content          │  │   │
│  │  └───────────────────────────┘  │   │
│  └─────────────────────────────────┘   │
└────────────────────────────────────────┘
@end
@table
Layer | Meaning | Property
Content | Text, images | `width`, `height`
Padding | Space inside the border | `padding`
Border | The edge | `border`
Margin | Space outside, between elements | `margin`
@end
@code css
.box {
  width: 300px;
  padding: 20px;               /* all sides */
  padding: 10px 20px;          /* top/bottom  left/right */
  padding: 5px 10px 15px 20px; /* top right bottom left (clockwise) */
  border: 2px solid #15803d;
  margin: 0 auto;              /* centre a block horizontally */
}
@end
@topic 📐 box-sizing
@code css
/* Default (content-box): 300 + 2×20 padding + 2×2 border = 344px wide */
/* border-box: padding and border fit INSIDE the 300px */
*, *::before, *::after { box-sizing: border-box; }
@end
@tip Put `box-sizing: border-box` on every element at the start of every project — widths then behave the way you expect.
@topic 🤝 Margin Collapse
@code css
h2 { margin-bottom: 30px; }
p  { margin-top: 20px; }
/* The gap between them is 30px, not 50px: vertical margins collapse to the larger one */
@end
@info Margins collapse only **vertically** between normal block elements — not inside flex or grid containers.
@topic 🟩 Borders, Radius, Shadows and Outline
@code css
.card {
  border: 1px solid #e5e7eb;
  border-radius: 12px;                          /* rounded corners */
  box-shadow: 0 4px 12px rgb(0 0 0 / .08);     /* x y blur colour */
}
.avatar { border-radius: 50%; }                  /* circle */
.btn:focus-visible { outline: 3px solid #15803d; outline-offset: 2px; }  /* doesn't change layout */
@end
@practice
1. Calculate the total width of a 200px box with 15px padding, a 5px border and 10px margin, with and without border-box.
2. Centre a 600px container horizontally.
3. Make a circular profile image with a border and a shadow.
4. Show margin collapse between two paragraphs and then prevent it with a flex container.
@interview Every element is a box of content, padding, border and margin; box-sizing: border-box includes padding and border in the width, and adjacent vertical margins collapse to the larger value.

@module m9 | 👁️ | 9 · Display | Module 9 — Display, Visibility & Overflow | block · inline · inline-block · none · visibility · overflow
@topic 👁️ The display Property
@table
Value | Behaviour | Width/height apply?
`block` | New line, full width (div, p, h1) | Yes
`inline` | Flows within text (span, a, strong) | No
`inline-block` | Flows within text but keeps box sizes | Yes
`none` | Removed from the page completely | —
`flex` / `grid` | Turns the element into a layout container | Yes
@end
@code css
nav a   { display: inline-block; padding: 8px 12px; }  /* clickable area with padding */
.hidden { display: none; }
@end
@topic 🙈 Ways to Hide
@table
CSS | Visible? | Takes space? | Screen readers?
`display: none` | No | No | Hidden
`visibility: hidden` | No | Yes | Hidden
`opacity: 0` | No | Yes | Still read
`.visually-hidden` pattern | No | No | Still read
@end
@code css
/* Hidden visually but still announced by screen readers */
.visually-hidden {
  position: absolute; width: 1px; height: 1px;
  overflow: hidden; clip-path: inset(50%); white-space: nowrap;
}
@end
@topic 📜 Overflow
@code css
.box   { height: 150px; overflow: auto; }   /* scrollbars only when needed */
.clip  { overflow: hidden; }                /* cut off extra content */
.x     { overflow-x: auto; }                /* sideways scrolling, e.g. wide tables */
@end
@practice
1. Turn a list of links into a horizontal menu with `inline-block`.
2. Toggle a message between `display: none` and `visibility: hidden` and compare the layout.
3. Make a fixed-height chat box that scrolls when messages overflow.
4. Hide a "Skip to content" link visually but keep it for screen readers.
@interview display controls how an element is laid out (block, inline, inline-block, none, flex, grid); display:none removes it, visibility:hidden hides it but keeps its space, and overflow controls extra content.

@module m10 | 📍 | 10 · Position | Module 10 — Positioning | static · relative · absolute · fixed · sticky · z-index
@topic 📍 The position Property
@table
Value | Positioned relative to | Stays in the page flow?
`static` | Nothing (default) | Yes
`relative` | Its own normal position | Yes (space is kept)
`absolute` | Nearest positioned ancestor | No
`fixed` | The viewport (screen) | No — stays while scrolling
`sticky` | Scrolls normally, then sticks at `top` | Yes
@end
@code css
.card   { position: relative; }                     /* anchor for the badge */
.badge  { position: absolute; top: 8px; right: 8px; }

.navbar { position: sticky; top: 0; z-index: 10; }  /* sticks when scrolled */
.chat   { position: fixed; bottom: 20px; right: 20px; }
.cover  { position: absolute; inset: 0; }           /* top/right/bottom/left: 0 */
@end
@topic 🎯 Centering with Position
@code css
.parent { position: relative; height: 300px; }
.child  {
  position: absolute;
  top: 50%; left: 50%;
  transform: translate(-50%, -50%);   /* move back by half its own size */
}
@end
@topic 🥞 z-index and Stacking
- `z-index` decides which overlapping element is on top: higher numbers are in front.
- It works on positioned elements (not `static`) and on flex/grid items.
- `z-index`, `opacity` below 1 and `transform` create a new **stacking context**: children can't escape above elements outside it.
@warn `position: sticky` does nothing without `top` (or bottom), and it stops working if a parent has `overflow: hidden`.
@practice
1. Put a "SALE" badge in the top-right corner of a product card.
2. Build a navbar that sticks to the top while scrolling.
3. Add a floating "Chat with us" button that stays in the bottom-right corner.
4. Create a full-screen modal overlay with a centred box.
5. Why doesn't my `z-index: 999` work? List two possible reasons.
@interview relative shifts an element from its normal spot, absolute places it relative to the nearest positioned ancestor, fixed pins it to the viewport, sticky switches from normal to fixed at a threshold, and z-index orders overlapping positioned elements.

@module m11 | 🧲 | 11 · Flexbox | Module 11 — Flexbox | Flex container · Main & cross axis · justify-content · align-items · wrap · gap · flex items
@topic 🧲 One-Dimensional Layout
Flexbox lays items out in **one direction** — a row or a column — and distributes space between them.
@code css
.container {
  display: flex;
  flex-direction: row;          /* row | column | row-reverse | column-reverse */
  justify-content: space-between; /* along the main axis */
  align-items: center;          /* along the cross axis */
  flex-wrap: wrap;              /* allow items to wrap to new lines */
  gap: 16px;                    /* space between items */
}
@end
@table
Container property | Common values | Controls
`flex-direction` | `row`, `column` | Main axis direction
`justify-content` | `flex-start`, `center`, `space-between`, `space-around`, `space-evenly` | Spacing on the main axis
`align-items` | `stretch`, `center`, `flex-start`, `flex-end`, `baseline` | Alignment on the cross axis
`flex-wrap` | `nowrap`, `wrap` | Wrapping onto new lines
`align-content` | `flex-start`, `center`, `space-between` | Spacing between wrapped lines
`gap` | `16px`, `1rem 2rem` | Space between items
@end
@topic 🧩 Flex Items
@code css
.item   { flex: 1; }            /* grow equally to fill space (1 1 0%) */
.side   { flex: 0 0 250px; }    /* don't grow, don't shrink, 250px basis */
.main   { flex: 2; }            /* twice the share of flex: 1 items */
.last   { order: 3; }           /* change visual order */
.odd    { align-self: flex-end; }/* override align-items for one item */
.push   { margin-left: auto; }  /* push this item (and the rest) to the right */
@end
@table
Item property | Meaning
`flex-grow` | How much of the free space it takes
`flex-shrink` | How much it shrinks when space is short
`flex-basis` | Starting size before growing or shrinking
`flex` | Shorthand: grow shrink basis
`order` | Visual order (default 0)
`align-self` | Cross-axis alignment for this item only
@end
@topic 🛠️ Common Patterns
@code css
/* Perfect centering */
.center { display: flex; justify-content: center; align-items: center; min-height: 100vh; }

/* Navbar: logo left, links right */
.nav { display: flex; align-items: center; justify-content: space-between; padding: 0 20px; }

/* Equal-width cards that wrap */
.cards { display: flex; flex-wrap: wrap; gap: 20px; }
.cards > * { flex: 1 1 250px; }
@end
@tip Practise with Flexbox Froggy (flexboxfroggy.com) — it's a game that teaches every property.
@practice

@module m12 | 🔲 | 12 · Grid | Module 12 — CSS Grid | Columns & rows · fr · repeat · minmax · auto-fit · Spanning · Template areas
@topic 🔲 Two-Dimensional Layout
Grid controls **rows and columns at the same time** — ideal for page layouts and card galleries.
@code css
.grid {
  display: grid;
  grid-template-columns: 200px 1fr 1fr;   /* fixed + two flexible columns */
  grid-template-rows: auto 1fr auto;
  gap: 20px;
}
.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));   /* responsive with no media queries */
  gap: 16px;
}
@end
@table
Term | Meaning
`fr` | A fraction of the free space
`repeat(3, 1fr)` | Three equal columns
`minmax(220px, 1fr)` | At least 220px, at most one fraction
`auto-fill` | Creates as many columns as fit (keeps empty tracks)
`auto-fit` | Same, but collapses empty tracks so items stretch
`gap` | Space between rows and columns
@end
@topic ↔️ Placing and Spanning Items
@code css
.featured { grid-column: span 2; }        /* take two columns */
.banner   { grid-column: 1 / -1; }        /* from the first line to the last: full width */
.tall     { grid-row: span 2; }
.box      { grid-column: 2 / 4; grid-row: 1 / 3; }   /* start line / end line */
@end
@topic 🗺️ Template Areas: a Page Layout
@code css
.page {
  display: grid;
  grid-template-columns: 250px 1fr;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
  min-height: 100vh;
}
header { grid-area: header; }
aside  { grid-area: sidebar; }
main   { grid-area: main; }
footer { grid-area: footer; }

@media (max-width: 700px) {
  .page { grid-template-columns: 1fr;
          grid-template-areas: "header" "main" "sidebar" "footer"; }
}
@end
@topic ⚖️ Flexbox vs Grid
@table
Flexbox | Grid
One dimension: a row **or** a column | Two dimensions: rows **and** columns
Content decides the size | The layout decides the size
Navbars, button groups, centring | Page layouts, galleries, dashboards
@end
@code css
.center-anything { display: grid; place-items: center; }   /* shortest way to centre */
@end
@tip Practise with Grid Garden (cssgridgarden.com).
@practice

2. Create a header / sidebar / main / footer layout with template areas.
3. Make a dashboard where one card spans two columns and another spans two rows.

@interview Grid is a two-dimensional layout using grid-template-columns/rows, fr units, repeat(), minmax() and gap; items span tracks with grid-column/grid-row, and template areas name page regions.

@module m14 | 🔄 | 14 · Transitions | Module 14 — Transitions & Transforms | transition · timing functions · translate · rotate · scale · skew · 3D
@topic 🔄 Transitions
A transition animates a property **smoothly from one value to another** when it changes (for example on hover).
@code css
.btn {
  background: #15803d;
  transition: background-color .3s ease, transform .2s ease;   /* property duration timing */
}
.btn:hover {
  background: #166534;
  transform: translateY(-2px);
}
@end
@table
Property | Example
`transition-property` | `background-color`, `transform`
`transition-duration` | `.3s`, `300ms`
`transition-timing-function` | `ease`, `linear`, `ease-in-out`, `cubic-bezier(.2,.8,.2,1)`
`transition-delay` | `.1s`
@end
@warn Avoid `transition: all` — it animates properties you didn't intend and can hurt performance.
@topic 🌀 2D Transforms
@code css
.move   { transform: translate(20px, 10px); }   /* move */
.spin   { transform: rotate(45deg); }
.grow   { transform: scale(1.1); }
.slant  { transform: skewX(-10deg); }
.combo  { transform: translateY(-4px) scale(1.02); }   /* combine, applied right to left */
.origin { transform-origin: top left; }          /* pivot point */
@end
@topic 🧊 3D Transforms: Flip Card
@code css
.flip        { perspective: 1000px; }
.flip-inner  { transition: transform .6s; transform-style: preserve-3d; position: relative; }
.flip:hover .flip-inner { transform: rotateY(180deg); }
.front, .back { position: absolute; inset: 0; backface-visibility: hidden; }
.back        { transform: rotateY(180deg); }
@end
@tip Animate `transform` and `opacity` for smooth 60fps motion. Animating `width`, `top` or `margin` forces the browser to recalculate layout.
@practice
1. Create buttons that lift and change colour smoothly on hover.
2. Make an image zoom in slightly inside its frame on hover (`overflow: hidden` + `scale`).
3. Build a card that flips over on hover to show its back.
4. Rotate an arrow icon 180° when a menu opens.
@interview Transitions animate property changes over time with a duration and timing function, while transform moves, rotates, scales and skews elements without affecting layout; transform and opacity animate most smoothly.

@module m15 | 🎞️ | 15 · Animations | Module 15 — Keyframe Animations | @keyframes · animation properties · Loaders · Reduced motion
@topic 🎞️ @keyframes
@code css
@keyframes fadeUp {
  from { opacity: 0; transform: translateY(20px); }
  to   { opacity: 1; transform: translateY(0); }
}
.card { animation: fadeUp .6s ease-out both; }

@keyframes pulse {
  0%, 100% { transform: scale(1); }
  50%      { transform: scale(1.08); }
}
.badge { animation: pulse 1.5s ease-in-out infinite; }
@end
@table
Property | Example | Meaning
`animation-name` | `fadeUp` | Which @keyframes to run
`animation-duration` | `.6s` | Length of one cycle
`animation-timing-function` | `ease-out`, `steps(4)` | Speed curve
`animation-delay` | `.2s` | Wait before starting
`animation-iteration-count` | `3`, `infinite` | How many times
`animation-direction` | `alternate`, `reverse` | Play order
`animation-fill-mode` | `forwards`, `both` | Keep the first/last frame's styles
`animation-play-state` | `paused` | Pause and resume
@end
@topic ⏳ A Loading Spinner

  width: 40px; height: 40px;
  border: 4px solid #d1fae5;
  border-top-color: #15803d;

@end
@topic ♿ Respect Reduced Motion
@code css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: .01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: .01ms !important;
  }
}
@end
@practice
1. Fade cards in one after another using `animation-delay`.
2. Build a loading spinner and a three-dot "typing…" animation.
3. Animate a heart that beats continuously.
4. Make a text typing effect with `steps()`.
5. What is the difference between a transition and an animation?
@interview @keyframes define the stages of an animation and the animation properties set its duration, timing, delay, repetition and fill mode; unlike transitions, animations can run on their own and loop, and should respect prefers-reduced-motion.

@module m16 | 🧪 | 16 · Variables | Module 16 — CSS Variables (Custom Properties) | :root · var() · Fallbacks · Scope · Theming · JavaScript
@topic 🧪 Defining and Using Variables

@code css

  --bg: #ffffff;
  --text: #14201a;
}

  --text: #e5f2e9;
}

@end

  root.style.setProperty("--primary", "#2563eb");

</script>
@end
@practice
1. Move every colour and spacing value of a page into `:root` variables.

@interview Custom properties (--name) are defined, often on :root, and read with var() with an optional fallback; they are inherited and can be changed per component, per theme or from JavaScript.

@topic ✅ Best-Practice Checklist
- Use classes for styling; keep specificity low; avoid `!important`
- Put colours, spacing and fonts in CSS variables
- Mobile-first, with `rem` for type and relative units for layout
- Visible `:focus-visible` styles and colour contrast of at least 4.5:1 for text
- Animate `transform` and `opacity`; respect `prefers-reduced-motion`
- Debug with DevTools: inspect an element, toggle rules, see the box model and computed styles
- Minify CSS for production and remove unused rules

@end

@topic Q: What is the CSS cascade?
The cascade determines which declarations apply when rules compete. It considers relevance, origin and importance, cascade layers, specificity, scoping proximity where applicable, and source order; the exact ordering depends on the declarations being compared.
@topic Q: How is selector specificity compared?
Specificity is compared in categories: ID selectors, class/attribute/pseudo-class selectors, then type/pseudo-element selectors. A higher category wins before lower categories are considered; source order resolves otherwise equal declarations within the same cascade context.
@topic Q: What does `box-sizing: border-box` change?
It makes an element's declared width and height include its padding and border, simplifying predictable sizing. Margins remain outside the box.
@topic Q: What is the difference between Flexbox and Grid?
Flexbox is primarily suited to arranging items along one main axis, with alignment on the cross axis. Grid is designed for two-dimensional row-and-column layouts; the two can be combined.
@topic Q: What is the difference between `align-items` and `justify-content` in Flexbox?
`justify-content` distributes items along the main axis, while `align-items` aligns them along the cross axis. The axes change when `flex-direction` changes.
@topic Q: What does the `fr` unit mean in CSS Grid?
An `fr` unit represents a share of the available space in a grid container after fixed and intrinsic sizing contributions are considered. It is not simply a percentage of the container in every situation.
@topic Q: How does `position: sticky` behave?
A sticky element participates in normal flow, then sticks relative to its scroll container after reaching an inset threshold. Ancestor overflow and the available scroll container affect its behavior.
@topic Q: What containing block does an absolutely positioned element use?
It is positioned relative to its nearest ancestor that establishes an absolute-positioning containing block, commonly an ancestor with a non-static position. If none exists, it uses the initial containing block.
@topic Q: What creates a stacking context?
Properties such as positioned elements with a non-auto `z-index`, transforms, opacity below one, and isolation can create stacking contexts. A child cannot use `z-index` to escape its ancestor's stacking context.
@topic Q: How does inheritance work in CSS?
Some properties, such as `color` and font properties, inherit by default; many box and layout properties do not. Explicit inherited values can be set with `inherit`, `initial`, `unset`, or `revert` according to the intended behavior.
@topic Q: What is the difference between `em` and `rem`?
`em` is relative to the relevant element's computed font size, which can compound through nesting in some properties. `rem` is relative to the root element's font size.
@topic Q: How would you build a responsive layout without device-specific breakpoints for every screen?
Use fluid constraints such as flexible grid tracks, `minmax`, `auto-fit`, percentages, and bounded containers. Add media queries when the design needs a meaningful layout change rather than targeting particular devices.
@topic Q: What is the difference between a media query and a container query?
A media query responds to environment features such as viewport width or reduced-motion preference. A container query responds to the size or style of a designated ancestor container.
@topic Q: What does `:focus-visible` provide?
It targets focus indication when the browser determines a visible focus cue is appropriate, commonly for keyboard navigation. Preserve a clear indicator so users can identify the active control.
@topic Q: How should animation respect reduced-motion preferences?
Use the `prefers-reduced-motion` media feature to reduce or remove nonessential motion for users who request it. Keep state changes understandable without animation.
@topic Q: What is the difference between `display: none` and `visibility: hidden`?
`display: none` removes the element from layout; `visibility: hidden` hides it while retaining its layout space. Both generally remove it from the accessibility tree, though semantics and browser behavior should be tested for the use case.
@topic Q: What causes vertical margin collapsing?
In certain block formatting contexts, adjacent vertical margins can combine into one margin rather than add. Flex and Grid containers do not collapse item margins in the same way; padding, borders, or a new formatting context can change collapse behavior.
@topic Q: How can CSS custom properties support theming?
Define tokens such as colors and spacing with `--name` properties, often on `:root` or a theme container, then consume them with `var()`. Their inheritance lets a subtree override values without duplicating component rules.
@topic Q: Why use `minmax(0, 1fr)` for a Grid track?
The zero minimum allows the track to shrink below its min-content contribution, helping prevent long content from forcing overflow. Add `min-width: 0` to grid or flex children when their intrinsic size still causes overflow.
@topic Q: What makes a form control styling accessible?
Keep a visible label, sufficient text and focus contrast, clear focus and error states, and usable target sizes. Do not rely on color alone to convey status, and preserve keyboard operation.
