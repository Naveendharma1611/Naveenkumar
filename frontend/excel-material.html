Module 1 — Introduction to Excel & the Interface

Ribbon · Workbook · Worksheet · Navigation

▼

🖥️ The ribbon and Quick Access Toolbar

Excel organizes every command into the ribbon, a set of tabs (Home, Insert, Page Layout, Formulas, Data, Review, View) each split into labeled groups like Font, Alignment and Number on the Home tab. The Quick Access Toolbar above or below the ribbon holds commands you use constantly, such as Save and Undo, so you don't have to hunt through tabs. Right-clicking any ribbon command lets you add it to the Quick Access Toolbar, and Ctrl+F1 toggles the ribbon's visibility to reclaim screen space.

📁 Workbook, worksheet, cell

A workbook is the Excel file itself; it can contain many worksheets (tabs at the bottom), and each worksheet is a grid of cells identified by a column letter and row number such as A1. A range is a rectangular block of cells, written as A1:C10, and is the basic unit that formulas and functions operate on. Renaming and color-coding sheet tabs, and grouping related sheets, keeps larger workbooks navigable as they grow.

🧭 Navigation and file formats

Ctrl+Arrow jumps to the edge of a contiguous data block, Ctrl+Home/Ctrl+End jump to A1 or the last used cell, and Ctrl+PageDown/Ctrl+PageUp move between sheets. F5 or Ctrl+G opens Go To, which combined with Go To Special can select only visible cells, formulas, blanks or constants in one step. Choosing the right save format matters for collaboration and automation.

FormatWhen to use it
.xlsxStandard workbook, no macros, smallest and safest default
.xlsmWorkbook that contains VBA macros
.xlsLegacy format for Excel 97-2003 compatibility
.csvPlain tabular data only — no formulas, formatting or multiple sheets
.pdfFixed, read-only layout for sharing or printing a report
Pin frequently used workbooks and folders in the Open/Save dialog's recent list so you don't re-navigate folder trees every day.

🏋️ Practice Questions

  1. Open a blank workbook, rename Sheet1 to "Data", and add two more sheets named "Summary" and "Notes".
  2. Explain to a colleague why saving a multi-sheet workbook with formulas as .csv would lose information.
🎤 One-Line Interview AnswerExcel organizes work as a workbook of worksheets made of cells and ranges, and the ribbon groups every command by task; choosing .xlsx, .xlsm or .csv correctly depends on whether you need macros or just flat data.

Module 2 — Entering, Formatting & Editing Data

Data Types · Number Formats · AutoFill · Flash Fill

▼

✍️ Data types Excel recognizes

Excel auto-detects the type you type: plain text is left-aligned, numbers and dates are right-aligned, and booleans (TRUE/FALSE) and errors (#N/A, #REF!) have their own display rules. A number format only changes how a value is displayed, never the underlying value stored in the cell — a cell holding 0.5 can be displayed as 50%, $0.50, or 1/2 without changing the number itself. This distinction is a frequent source of confusion: formulas always calculate on the real stored value, not the formatted text.

🔢 Custom number formats

Built-in formats cover Currency, Accounting, Percentage, Date and Scientific, but custom format codes give full control, for example #,##0.00;[Red](#,##0.00) shows negative numbers in red with parentheses. The four sections of a custom format, separated by semicolons, are positive;negative;zero;text.

#,##0;[Red]-#,##0;"-";@

⚡ AutoFill and Flash Fill

AutoFill (drag the fill handle) extends a detected pattern — numbers, dates, weekdays, or a custom list — across adjacent cells. Flash Fill (Ctrl+E) looks at an example you type next to existing data and infers the transformation, such as splitting "John Smith" into first and last name columns, without writing a single formula.

FeatureBest forTrigger
AutoFillExtending sequences and formulasDrag the fill handle or double-click it
Flash FillReformatting or splitting text by exampleCtrl+E after typing one example

🏋️ Practice Questions

  1. Use AutoFill to generate the weekdays Mon-Fri down a column from a single starting cell.
  2. Use Flash Fill to extract the domain name from a column of email addresses.
🎤 One-Line Interview AnswerExcel separates a cell's stored value from its displayed format, so custom number formats change appearance only; AutoFill extends detected patterns while Flash Fill learns a transformation from one typed example.

Module 3 — Cell References & Formula Basics

Relative · Absolute · Mixed · Operators

▼

🧮 Relative, absolute and mixed references

A relative reference (A1) shifts when copied to another cell; an absolute reference ($A$1) stays fixed on both column and row; a mixed reference ($A1 or A$1) locks only the column or only the row. Pressing F4 while editing a reference cycles through all four reference styles. Getting this wrong is the single most common formula bug in Excel — a tax-rate cell referenced relatively will silently point to a blank cell as the formula is copied down.

=B2*$D$1
Result
Copied toFormula becomes
C2=C2*$D$1
B3=B3*$D$1

➕ Operators and order of operations

Excel evaluates formulas using standard order of operations: parentheses, then exponents (^), then multiplication/division (*, /), then addition/subtraction (+, -), and finally comparison operators (=, <>, >, <). The & operator concatenates text, and : , , and space are the three reference operators (range, union, intersection). When in doubt, add explicit parentheses — they cost nothing and remove ambiguity for the next person reading the sheet.

ExpressionResultWhy
=2+3*414Multiplication before addition
=(2+3)*420Parentheses override default order
=2^2^364^ evaluates left to right as (2^2)^3
A formula that starts with a number or a dash is treated as text unless it begins with =, +, or - in cell-formula context; always start formulas with = for clarity.

🏋️ Practice Questions

  1. Write a formula using a mixed reference so that copying it across columns keeps the row fixed but lets the column move.
  2. Predict the result of =10-2*3^2 and verify it in Excel.
🎤 One-Line Interview AnswerRelative references shift on copy, absolute references ($A$1) stay fixed, and mixed references lock only a row or column; Excel evaluates parentheses, exponents, multiplication/division and then addition/subtraction, in that order.

Module 4 — Logical Functions

IF · IFS · AND/OR/NOT · IFERROR

▼

🔀 IF, nested IF and IFS

IF(condition, value_if_true, value_if_false) is the core branching function. Nesting several IFs inside each other handles more than two outcomes but becomes hard to read past two or three levels; IFS(cond1, val1, cond2, val2, ...) replaces deeply nested IFs with a flat, readable list of condition-result pairs evaluated in order.

=IFS(A2>=90,"A",A2>=75,"B",A2>=60,"C",TRUE,"F")
Result
A2Formula result
95A
80B
40F

🔗 AND, OR, NOT

AND(...) returns TRUE only if every argument is TRUE; OR(...) returns TRUE if any argument is TRUE; NOT(...) flips a logical value. These combine naturally inside IF, for example =IF(AND(A2>50,B2="Yes"),"Approve","Reject") approves only when both conditions hold.

🛟 IFERROR and IFNA

IFERROR(formula, value_if_error) catches any error a formula might return and substitutes a friendlier value, which is essential when wrapping lookups that might not find a match. IFNA is the narrower version that catches only #N/A, letting other genuine errors (like #DIV/0! from a real bug) surface instead of being silently hidden.

=IFERROR(VLOOKUP(A2,Prices,2,FALSE),"Not found")
Prefer IFNA over IFERROR around lookups when you want formula bugs like a bad range to stay visible instead of being masked.

🏋️ Practice Questions

  1. Replace a 4-level nested IF that assigns letter grades with an equivalent IFS formula.
  2. Write a formula that approves a loan only if credit score is above 700 AND income is above 50000.
🎤 One-Line Interview AnswerIF branches on one condition, IFS replaces nested IFs with readable condition-result pairs, AND/OR/NOT combine multiple conditions, and IFERROR or the narrower IFNA catches errors so they display something meaningful instead of breaking the sheet.

Module 5 — Lookup & Reference Functions

VLOOKUP · INDEX/MATCH · XLOOKUP · OFFSET

▼

🔍 VLOOKUP and its limits

VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup]) searches the first column of a range top to bottom and returns a value from a column to its right, counted by position. Its two big limitations are that it can only look rightward from the lookup column, and inserting or deleting a column shifts col_index_num and silently breaks the formula. Always set the fourth argument to FALSE for an exact match unless you deliberately want approximate matching on sorted data.

=VLOOKUP(D2,A2:B100,2,FALSE)

🎯 INDEX/MATCH — the flexible alternative

MATCH(lookup_value, lookup_array, 0) returns the position of a value in a range; INDEX(array, row_num, [col_num]) returns the value at a given position. Combined, INDEX(return_range, MATCH(lookup_value, lookup_range, 0)) can look leftward, is immune to inserted columns because each range is referenced independently, and is generally faster on large sheets since MATCH only scans one column.

=INDEX(B2:B100,MATCH(D2,A2:A100,0))
Result
Lookup valueA2:A100 position foundReturned from B2:B100
"Widget"7142.50

⚡ XLOOKUP and HLOOKUP

XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found]) is the modern successor available in Excel 365/2021+: it searches in either direction, defaults to exact match (safer than VLOOKUP's default), handles "not found" natively without wrapping in IFERROR, and can return an entire row or column at once. HLOOKUP is VLOOKUP's horizontal twin, searching the first row of a table and returning from a row below it — useful when data is laid out with field names across columns instead of down rows.

=XLOOKUP(D2,A2:A100,B2:B100,"Not found")

📍 OFFSET for dynamic ranges

OFFSET(reference, rows, cols, [height], [width]) returns a reference shifted and resized from a starting cell — useful for building dynamic named ranges that grow with new data, but it is a volatile function that recalculates on every single sheet change, which can slow down large workbooks. INDEX can often achieve the same dynamic-range effect non-volatilely and is generally preferred.

FunctionDirectionExact match defaultBreaks if column inserted?
VLOOKUPRight onlyNo (approximate)Yes
INDEX/MATCHEitherYou choose (use 0)No
XLOOKUPEitherYesNo

🏋️ Practice Questions

  1. Convert a VLOOKUP formula that looks up an employee ID into an INDEX/MATCH that returns the employee's department, which sits to the left of the ID column.
  2. Rewrite the same lookup using XLOOKUP and add a "Not found" default.
  3. Explain why OFFSET-based named ranges can slow down a large workbook.
🎤 One-Line Interview AnswerVLOOKUP only looks rightward and breaks when columns are inserted because it counts columns by position; INDEX/MATCH fixes both problems by referencing the lookup and return ranges independently, and XLOOKUP is the modern function that looks either direction, defaults to exact match, and handles missing values natively — which is why it's replacing VLOOKUP in new workbooks.

Module 6 — Text Functions

LEFT/RIGHT/MID · CONCAT/TEXTJOIN · TRIM/SUBSTITUTE

▼

🔤 Extracting substrings

LEFT(text, n) and RIGHT(text, n) grab characters from either end; MID(text, start, n) grabs from the middle. FIND(find_text, text) is case-sensitive and returns the position of a substring, while SEARCH does the same but is case-insensitive and supports wildcards — combining MID with FIND lets you extract text between two delimiters even when the surrounding text length varies.

=MID(A2,FIND("-",A2)+1,FIND("-",A2,FIND("-",A2)+1)-FIND("-",A2)-1)

🧵 Joining and cleaning text

CONCAT joins values together; TEXTJOIN(delimiter, ignore_empty, range) is more powerful because it can join an entire range with a chosen separator while skipping blanks in one step. TRIM removes extra spaces (keeping single spaces between words), which is essential before comparing or looking up text imported from another system, since invisible trailing spaces silently break exact matches.

=TEXTJOIN(", ",TRUE,B2:B5)
Result
B2:B5TEXTJOIN result
"Apples","","Bread","Milk"Apples, Bread, Milk

🔧 Replacing and reformatting text

SUBSTITUTE(text, old, new) replaces text by matching the actual characters, while REPLACE(text, start, num_chars, new) replaces by position — use SUBSTITUTE when you know the content, REPLACE when you know the position. TEXT(value, format) converts a number or date into a formatted string, e.g. =TEXT(TODAY(),"mmmm yyyy"), and UPPER/LOWER/PROPER standardize case for consistent reporting and matching.

🏋️ Practice Questions

  1. Split a column of "Last, First" names into separate First and Last columns using text functions.
  2. Use TEXTJOIN to combine a street, city and postal code column into one address string, skipping any blank fields.
🎤 One-Line Interview AnswerLEFT/RIGHT/MID extract by position while FIND/SEARCH locate delimiters so extraction works on variable-length text; TEXTJOIN is the modern way to combine a whole range with a separator while skipping blanks, and TRIM is a standard first step for cleaning imported data before any lookup or comparison.

Module 7 — Date & Time Functions

TODAY/NOW · DATEDIF · NETWORKDAYS/WORKDAY

▼

📅 Dates are serial numbers

Excel stores every date as a serial number counting days from January 1, 1900, which is why dates can be added, subtracted and compared like plain numbers; a time is stored as the decimal fraction of a 24-hour day. TODAY() returns the current date and NOW() returns the current date and time, both volatile and recalculating whenever the sheet changes.

⏳ DATEDIF and EOMONTH

DATEDIF(start, end, unit) calculates the difference between two dates in years ("y"), months ("m") or days ("d") — it is undocumented in the function picker but fully supported, and is the standard way to compute someone's age or tenure. EOMONTH(start_date, months) returns the last day of a month that many months before or after the start date, which is useful for computing invoice due dates or month-end reporting periods.

=DATEDIF(B2,TODAY(),"y")&" years, "&DATEDIF(B2,TODAY(),"ym")&" months"

📆 NETWORKDAYS and WORKDAY

NETWORKDAYS(start, end, [holidays]) counts working days (Mon-Fri, excluding an optional holiday list) between two dates — the standard way to compute SLA or turnaround time. WORKDAY(start, days, [holidays]) does the reverse: given a start date and a number of working days to add, it returns the resulting date, skipping weekends and holidays.

=WORKDAY(A2,10,Holidays)
Result
Start dateWorking days to addResult (skipping weekends/holidays)
2026-01-05102026-01-19
Keep a named range of company holidays and feed it into every NETWORKDAYS/WORKDAY formula so date calculations stay correct year over year.

🏋️ Practice Questions

  1. Calculate a person's age in completed years from their date of birth using DATEDIF.
  2. Compute the delivery date that is 15 working days after an order date, excluding a holiday list.
🎤 One-Line Interview AnswerExcel dates are really serial numbers, which is why date arithmetic just works; DATEDIF computes elapsed years/months/days, EOMONTH finds month-end dates, and NETWORKDAYS/WORKDAY handle business-day counting around weekends and a holiday list.

Module 8 — Math & Statistical Functions

SUM/AVERAGE/COUNT · SUMIFS · COUNTIFS

▼

🔢 The SUM/AVERAGE/COUNT family

SUM, AVERAGE, MAX, MIN operate on numeric ranges; COUNT counts numeric cells, COUNTA counts any non-blank cell, and COUNTBLANK counts empty cells — mixing these up is a very common mistake when auditing data completeness. SUMPRODUCT multiplies corresponding array elements and sums the result, making it a powerful tool for weighted sums or multi-condition logic without helper columns.

FunctionCounts/sums
COUNTNumeric cells only
COUNTAAny non-empty cell (text, number, date)
COUNTBLANKEmpty cells only
SUMPRODUCTElement-wise product then sum — great for weighted totals

🎯 SUMIF/SUMIFS and COUNTIF/COUNTIFS

SUMIF(range, criteria, sum_range) sums with one condition; SUMIFS(sum_range, crit_range1, crit1, crit_range2, crit2, ...) sums with multiple AND conditions — note the argument order flips between the two. COUNTIF/COUNTIFS follow the same pattern for counting matching rows instead of summing them.

=SUMIFS(Sales[Amount],Sales[Region],"West",Sales[Month],"Jan")
Result
RegionMonthAmount
WestJan1200
WestFeb900
EastJan700

📊 AVERAGEIFS and multi-criteria averages

AVERAGEIFS(avg_range, crit_range1, crit1, ...) averages values meeting multiple conditions, following the same argument order as SUMIFS. Criteria support wildcards ("West*") and comparison operators as text (">100"), which lets a single formula filter on ranges or partial text matches.

🏋️ Practice Questions

  1. Write a SUMIFS formula that totals sales for the "West" region in "Jan" only.
  2. Write a COUNTIFS formula that counts orders over $500 placed in the last 30 days.
🎤 One-Line Interview AnswerSUMIFS/COUNTIFS/AVERAGEIFS handle multiple AND conditions with sum_range or avg_range listed first, while the single-condition SUMIF/COUNTIF list the sum range last; SUMPRODUCT is the fallback for conditions those functions can't express directly, such as weighted sums across two arrays.

Module 9 — Data Validation & Error Checking

Dropdowns · Custom Rules · Common Errors

▼

✅ Dropdown lists and validation rules

Data > Data Validation lets you restrict a cell to a List (a typed set or a range reference, commonly an Excel Table column so the dropdown grows automatically), a number within a range, a date within a range, or text of a specific length. Checking "Show error alert" with a Stop style prevents invalid entries outright, while an Input Message guides the user before they type.

🧩 Custom validation and circular references

The Custom validation type accepts any formula that returns TRUE/FALSE, which lets you enforce business rules like "end date must be after start date" (=D2>C2) or "no duplicate IDs" (=COUNTIF($A$2:$A$100,A2)=1). A circular reference happens when a formula refers back to its own cell directly or through a chain of other formulas — Excel warns about this and shows 0 or the last calculated value until it's fixed, except when Iterative Calculation is deliberately enabled for techniques like circular-reference-based amortization models.

⚠️ Reading common error codes

Recognizing an error code immediately narrows down the cause.

ErrorTypical cause
#N/ALookup value not found (VLOOKUP/MATCH/XLOOKUP)
#REF!Formula refers to a cell that was deleted
#VALUE!Wrong data type used in a calculation (e.g. text where a number is expected)
#DIV/0!Division by zero or by a blank cell
#NAME?Misspelled function name or an undefined named range
####Column too narrow to display the number (not a formula error)

🏋️ Practice Questions

  1. Build a dropdown list in a cell that pulls its options from an Excel Table column.
  2. Write a custom validation rule that prevents entering a date earlier than today.
🎤 One-Line Interview AnswerData Validation restricts input to lists, ranges or a custom formula so bad data never gets entered in the first place, and recognizing errors like #N/A versus #REF! versus #VALUE! immediately tells you whether the problem is a missing match, a broken reference, or a type mismatch.

Module 10 — Sorting & Filtering

AutoFilter · Custom Sort · Advanced Filter

▼

🔃 AutoFilter for quick exploration

Data > Filter adds dropdown arrows to each header that let you tick specific values, filter by color, or apply text/number/date condition filters (contains, greater than, top 10, etc.) without altering the underlying row order. Filtering only hides rows — formulas referencing hidden rows still include them unless you use SUBTOTAL or AGGREGATE, which can be set to ignore hidden rows.

🔀 Custom multi-level sort

The Sort dialog (Data > Sort) supports sorting by multiple columns in sequence — e.g. by Region then by Sales descending within each region — and can sort by a custom list (like Jan, Feb, Mar instead of alphabetical) via "Custom List" in the sort order dropdown. Sorting is a destructive, one-time rearrangement of rows, unlike filtering which is reversible and non-destructive.

🧮 Advanced Filter

Data > Advanced lets you filter using a separate criteria range with more power than AutoFilter: OR logic across rows, formula-based criteria, and the ability to extract matching rows to a new location (via "Copy to another location") while also pulling only unique records.

ToolCan do OR logic across columns?Can extract to new range?Alters row order?
AutoFilterLimited (within one column)NoNo
Advanced FilterYesYesNo
SortNot applicableNoYes

🏋️ Practice Questions

  1. Filter a sales table to show only orders from "West" or "East" region, above $1,000.
  2. Use Advanced Filter with a criteria range to extract unique customer names into a new list.
🎤 One-Line Interview AnswerAutoFilter is the fast, reversible way to narrow down what you see, custom multi-level sort physically reorders rows including by custom lists, and Advanced Filter is the power tool for OR-logic and formula-based criteria plus extracting unique matching rows elsewhere.

Module 11 — Conditional Formatting

Built-in Rules · Formula Rules · Data Bars/Icon Sets

▼

🎨 Built-in highlight rules

Home > Conditional Formatting offers ready-made rules like Highlight Cell Rules (greater than, duplicate values) and Top/Bottom Rules (top 10%, above average) that need no formula — pick the rule, set the threshold, choose a format, done. These cover the majority of day-to-day highlighting needs quickly and consistently.

🧮 Formula-based rules

"New Rule > Use a formula to determine which cells to format" unlocks arbitrary logic. The key trick is that the formula is written relative to the active (top-left) cell of the selected range, and Excel then applies the same relative logic to every other cell in the range — so to highlight an entire row when column D says "Overdue", you select the full row range starting at A2 and enter =$D2="Overdue" with the column locked but the row relative.

=$D2="Overdue"

📊 Data bars, icon sets and color scales

Data bars show relative magnitude as an in-cell bar, color scales apply a gradient (e.g. red-yellow-green) across a range to show where values rank, and icon sets attach symbols (arrows, traffic lights) based on thresholds. These visual encodings turn a column of numbers into a scannable heat map without a separate chart, which is ideal inside dense tables or dashboards.

🏋️ Practice Questions

  1. Highlight every row in a table where the "Status" column equals "Overdue", using a formula-based rule applied to the whole row.
  2. Apply a 3-color scale to a column of test scores so low scores are red and high scores are green.
🎤 One-Line Interview AnswerBuilt-in conditional formatting rules cover common cases instantly, but formula-based rules give full control — the formula is anchored to the top-left cell of the selection with relative/absolute references deciding how it adapts across the range — and data bars, color scales and icon sets turn numeric columns into an at-a-glance visual summary.

Module 12 — Excel Tables & Named Ranges

Structured References · Ctrl+T · Defined Names

▼

🗂️ Turning a range into a Table

Ctrl+T converts a range into an Excel Table, which automatically expands formulas, formatting and conditional formatting to new rows as they're typed, gives you a header-row filter for free, and lets other formulas use structured references like Sales[Amount] instead of a hard range like C2:C500. A Table also makes PivotTables and charts built from it update their source range automatically as the table grows.

=SUM(Sales[Amount])

📌 Named ranges

Formulas > Define Name creates a named range (e.g. TaxRate for cell B1) that makes formulas self-documenting — =Revenue*TaxRate reads far better than =C2*$B$1. Names have a scope (workbook-wide or sheet-specific) and, unlike structured references, don't automatically grow, so they're best for single fixed values like constants, rates, or lookup table anchors rather than data that keeps expanding.

Auto-expands with new rowsYesNo

🏋️ Practice Questions

  1. Convert a plain range of monthly expenses into an Excel Table and write a SUM formula using its structured reference.
  2. Create a named range called CommissionRate for a single cell and use it in a formula instead of a cell reference.
🎤 One-Line Interview AnswerExcel Tables (Ctrl+T) auto-expand with new data and expose readable structured references that also auto-feed PivotTables and charts, while named ranges are best for fixed single values like a tax rate — using names and structured references instead of raw cell addresses makes formulas self-documenting and far easier to audit.

Module 13 — Charts & Data Visualization

Chart Types · Combo Charts · Best Practices

▼

📊 Choosing the right chart type

The chart type should match the comparison you're making: a column/bar chart compares discrete categories, a line chart shows a trend over continuous time, a pie chart shows parts of a whole only when there are few categories (ideally under 6), and a scatter chart shows the relationship between two numeric variables. Picking the wrong type — like a pie chart for 15 categories or a 3D chart for anything — actively misleads the reader instead of clarifying the data.

Chart typeBest for
Column/BarComparing discrete categories
LineTrend over continuous time
Pie/DoughnutParts of a whole, few categories
ScatterRelationship between two numeric variables
ComboTwo different scales or metrics together

🧩 Combo charts

A combo chart plots two or more series with different chart types or axes on one chart, for example monthly revenue as columns and conversion rate as a line on a secondary axis — this is essential whenever the series have very different scales (dollars vs. percentages). Insert > Combo Chart or right-click a series and choose "Change Series Chart Type" to configure it.

🖼️ Visualization best practices

Avoid 3D effects, which distort perceived proportions; avoid truncated y-axes on bar charts, which exaggerate differences; remove gridlines and borders that don't add information (chartjunk); and always label axes and add a clear, specific title rather than the default "Chart Title" placeholder. A well-designed chart should be understandable in under five seconds without needing the surrounding text.

🏋️ Practice Questions

  1. Build a combo chart showing monthly sales as columns and profit margin percentage as a line on a secondary axis.
  2. Take an existing pie chart with 12 slices and redesign it as a sorted bar chart, explaining why the bar chart communicates better.
🎤 One-Line Interview AnswerThe chart type should match the question — columns for category comparison, lines for trends, scatter for relationships — and combo charts handle two differently-scaled series on one axis; avoiding 3D effects, truncated axes and chartjunk is what separates a clear chart from a misleading one.

Module 14 — PivotTables

Rows/Columns/Values · Value Field Settings · Grouping

▼

🧩 Building a PivotTable

Insert > PivotTable turns a flat table into an interactive summary by dragging fields into four areas: Rows and Columns group data into categories, Values aggregates a numeric field (sum, count, average, etc.), and Filters restricts the whole report to a subset. Source data should be a clean Excel Table with one header row and no blank rows/columns so the Pivot's field list picks up every column correctly.

⚙️ Value Field Settings

Double-clicking a field in the Values area, or using its dropdown, opens Value Field Settings, where you can switch the aggregation (Sum, Count, Average, Max, Min, Distinct Count) and, under "Show Values As," display results as a % of Grand Total, % of Column Total, or Running Total instead of a raw number — this is how you turn a plain sum into a share-of-total or trend view without any formula.

📅 Grouping and calculated fields

Right-clicking a date field in Rows and choosing Group rolls daily dates up into Months, Quarters or Years in one click; numeric fields can similarly be grouped into bins (e.g. 0-20, 21-40). A Calculated Field (PivotTable Analyze > Fields, Items & Sets) adds a new aggregated metric computed from other Pivot fields, such as =Revenue-Cost, directly inside the Pivot.

AreaPurpose
RowsGroups records into categories down the page
ColumnsGroups records into categories across the page
ValuesAggregates a numeric field (sum, count, average...)
FiltersRestricts the entire report to a subset

🏋️ Practice Questions

  1. Build a PivotTable that shows total sales by region (rows) and by quarter (columns).
  2. Change a Values field to show "% of Grand Total" instead of the raw sum, and explain when that view is more useful.
🎤 One-Line Interview AnswerA PivotTable summarizes a flat table by dragging fields into Rows, Columns, Values and Filters; Value Field Settings controls the aggregation and lets you show percentages or running totals instead of raw sums, and grouping date or numeric fields turns granular data into clean reporting buckets with one click.

Module 15 — PivotCharts, Slicers & Timelines

Linked Charts · Interactive Filtering

▼

📈 PivotCharts

A PivotChart is a chart built directly from a PivotTable (Insert > PivotChart, or PivotTable Analyze > PivotChart) and stays linked to it — changing the underlying Pivot's layout or filters updates the chart automatically, and clicking chart buttons (its own built-in field buttons) can filter the data interactively too.

🎚️ Slicers

A Slicer (Insert > Slicer, or PivotTable Analyze > Insert Slicer) is a clickable button panel for a field's values that filters the Pivot visually, without needing to open a dropdown. A single Slicer can be connected to multiple PivotTables and PivotCharts at once (Slicer > Report Connections), which is exactly how interactive dashboards let one click update every chart on the page simultaneously.

⏱️ Timelines

A Timeline (Insert > Timeline) is a specialized slicer just for date fields, letting users scrub through Years, Quarters, Months or Days with a single draggable control instead of picking individual dates from a list — it's the standard control for "show me this quarter's numbers" on a dashboard.

Module 16 — Power Query (Get & Transform Data)

Import · Merge/Append · Applied Steps

▼

🔄 Importing and the query editor

Data > Get Data connects to sources like Excel/CSV files, folders, databases, and web pages, loading them into the Power Query Editor where every cleaning action — removing a column, changing a type, filtering rows — is recorded as a step rather than applied destructively. This means the whole transformation can be refreshed against new data later (Data > Refresh All) without redoing any manual work.

🧵 Merge vs. Append

Merge Queries joins two queries side by side on a matching key column, similar to a SQL join (Inner, Left Outer, Right Outer, Full Outer, etc.) — it's the Power Query equivalent of a smarter, auditable VLOOKUP across whole tables. Append Queries instead stacks two or more queries with the same columns on top of each other, which is the standard way to combine monthly export files into one continuous table.

Under the hood each step is generated M code, viewable and editable in the Advanced Editor, for transformations the UI doesn't expose directly.

Module 17 — Power Pivot & the Data Model

Relationships · Star Schema · Beyond VLOOKUP

▼

🧠 Why plain VLOOKUP stops scaling

VLOOKUP and INDEX/MATCH work fine for small, single-table problems, but once you have several large tables (Sales, Customers, Products, Dates) that all need to relate to each other, maintaining lookup formulas across millions of rows becomes slow and error-prone, and a single worksheet also caps out around 1,048,576 rows. Power Pivot solves this by loading each table into an in-memory columnar Data Model that handles tens of millions of rows efficiently.

🔗 Relationships instead of lookups

Instead of writing a lookup formula per row, you define a relationship once between two tables on a common key (e.g. Sales[ProductID] to Products[ProductID]), and every PivotTable built from the model can then pull fields from both tables as if they were one — this is the classic star schema pattern, with a central fact table (Sales) connected to several dimension tables (Products, Customers, Dates). Relationships are one-to-many, and each table typically needs only one active relationship on a given key to avoid ambiguous filtering paths.

ApproachScales to millions of rows?Maintains relationships automatically?
VLOOKUP per rowNo — recalculates per row, slowNo, manual
Power Pivot Data ModelYes, in-memory columnar engineYes, defined once

  2. Build a PivotTable that shows total sales by Product Category, using fields pulled from both related tables.
🎤 One-Line Interview AnswerPower Pivot's Data Model replaces per-row lookup formulas with a relationship defined once between tables, typically in a star schema of one fact table and several dimension tables, which is what lets Excel analyze tens of millions of rows quickly instead of grinding through VLOOKUPs.

Module 18 — DAX Fundamentals

Calculated Columns vs Measures · CALCULATE

▼

📐 Calculated columns vs. measures

A calculated column is computed row by row and physically stored in the Data Model, taking up memory, and is appropriate when you need a value to slice or filter by (e.g. a "Price Band" column). A measure is computed on the fly at query time based on whatever filter context a PivotTable or report applies, is not stored per row, and is the right tool for nearly all aggregations like totals, ratios and year-over-year comparisons.

Total Sales := SUM(Sales[Amount])
Sales Last Year := CALCULATE([Total Sales], SAMEPERIODLASTYEAR('Date'[Date]))

🔧 CALCULATE and filter context

CALCULATE(expression, filter1, filter2, ...) is the single most important DAX function: it evaluates an expression inside a modified filter context, which is how you build things like "sales excluding returns" or "sales for this product category only regardless of the slicer." Every time-intelligence function (SAMEPERIODLASTYEAR, TOTALYTD, DATEADD) is really just a wrapper around CALCULATE manipulating the date filter.

🎤 One-Line Interview AnswerA calculated column is computed per row and stored in the model, which makes sense when you need to filter or group by it, while a measure is computed on demand within the current filter context, which is the right choice for totals and comparisons; CALCULATE is central because it lets you override that filter context deliberately.

Module 19 — What-If Analysis

Data Tables · Goal Seek · Scenario Manager

▼

🎯 Goal Seek

Goal Seek (Data > What-If Analysis > Goal Seek) works backward: you tell it which output cell to target, what value you want it to reach, and which single input cell to change, and it iteratively adjusts that input until the output matches — for example, finding the exact price needed to hit a target profit margin. It only changes one input at a time and only solves for one target cell.

📋 Data Tables

A Data Table (Data > What-If Analysis > Data Table) recalculates a formula across a whole range of possible input values in one step: a one-variable Data Table varies one input against a list of values (e.g. interest rate from 2% to 8%) and shows the resulting output for each; a two-variable Data Table varies two inputs simultaneously, producing a grid of results (e.g. loan amount vs. interest rate against monthly payment).

🗂️ Scenario Manager and Solver

Scenario Manager (Data > What-If Analysis > Scenario Manager) lets you save and switch between named sets of multiple input values at once (e.g. "Best Case," "Worst Case," "Likely") and compare their outputs side by side in a summary report — unlike Goal Seek or a Data Table, it can change several inputs together. Solver (an Excel add-in) goes further still, optimizing an objective cell by changing multiple variable cells subject to constraints, useful for problems like maximizing profit subject to a budget and capacity limit.

ToolInputs changedDirection
Goal SeekOneWorks backward from a target output
Data TableOne or twoShows output across a range of input values
Scenario ManagerMany, saved as named setsCompares named "what-if" cases
SolverMany, with constraintsOptimizes toward a best outcome

🏋️ Practice Questions

  1. Use Goal Seek to find the unit price needed to reach a target profit of $10,000 given fixed costs and volume.
  2. Build a two-variable Data Table showing monthly loan payment for different combinations of interest rate and loan term.
🎤 One-Line Interview AnswerGoal Seek solves backward for one input to hit one target output, a Data Table shows how a formula's output changes across a whole range of one or two inputs at once, and Scenario Manager saves and compares named sets of multiple inputs — Solver extends that further by optimizing multiple variables under constraints.

Module 20 — Array Formulas & Dynamic Arrays

UNIQUE · FILTER · SORT · SEQUENCE

▼

⚡ From legacy CSE arrays to spilling

Older array formulas required confirming with Ctrl+Shift+Enter (hence "CSE formulas") to process multiple values and return multiple results into a pre-selected range. Modern Excel (365/2021+) introduced dynamic arrays, which automatically "spill" results into as many neighboring cells as needed from a single formula entered normally with Enter — no CSE required, and the spilled range is marked with a light blue border and referenced as A2#.

🧩 UNIQUE, FILTER, SORT, SEQUENCE

UNIQUE(range) returns the distinct values in a range; FILTER(range, condition) returns only the rows matching a condition, replacing many older array-formula tricks; SORT(range, [sort_index], [order]) sorts a range by any column without touching the source data; SEQUENCE(rows, [cols], [start], [step]) generates a list of sequential numbers, handy for generating row numbers or date series dynamically.

=SORT(FILTER(A2:C100,C2:C100="West"),2,-1)
Result
FormulaBehavior
=UNIQUE(A2:A100)Spills a list of distinct values from column A
=FILTER(A2:C100,C2:C100="West")Spills only the rows where column C is "West"
=SORT(FILTER(...),2,-1)Filters to West, then sorts the result by column 2 descending

🔗 Referencing spilled ranges

Any formula can reference an entire spilled array by appending # to the top-left cell, e.g. =COUNTA(A2#) counts every value the dynamic array spilled, automatically adjusting if the spill grows or shrinks — this removes the need to guess a fixed range size up front.

  2. Use FILTER to spill only the rows where Status equals "Pending", then reference the spilled range with # in a COUNTA formula.
🎤 One-Line Interview AnswerDynamic arrays like UNIQUE, FILTER, SORT and SEQUENCE spill results automatically into neighboring cells from one formula entered normally, replacing older Ctrl+Shift+Enter array formulas, and the # spill reference lets other formulas track a spilled range's size automatically as it grows or shrinks.

Module 21 — Macros & VBA Basics

Macro Recorder · Sub/Function · Range Object

▼

🤖 Recording a macro

The Developer tab's Record Macro captures every click and keystroke as VBA code, which is the fastest way to automate a repetitive manual task without writing code from scratch — but the recorder generates literal, often inefficient code (e.g. selecting a cell before acting on it) that usually benefits from manual cleanup afterward. Recorded macros are saved in a .xlsm (macro-enabled) workbook or in the Personal Macro Workbook to be available across all workbooks.

🧱 Sub and Function structure

A Sub performs an action and does not return a value (Sub Name() ... End Sub), while a Function returns a value and can be called from a worksheet cell just like a built-in formula (Function Name() ... End Function). The Range object (Range("A1"), Cells(1,1), Range("A1:C10")) is how VBA reads and writes cell values, and .Value, .Formula, .Offset() and .End(xlDown) are the properties and methods used constantly to navigate and manipulate data.

Sub HighlightOverBudget()
    Dim cell As Range
    For Each cell In Range("C2:C100")
        If cell.Value > 1000 Then
            cell.Interior.Color = RGB(255, 199, 206)
        End If
    Next cell
End Sub

Function NetAfterTax(gross As Double, rate As Double) As Double
    NetAfterTax = gross * (1 - rate)
End Function

🧰 When VBA beats formulas

VBA is the right tool when a task needs to loop across an unpredictable number of files or sheets, interact with other applications (Outlook, Word), build a custom dialog box for user input, or perform an action (not just calculate a value) such as formatting, saving, or sending an email — formulas calculate values but cannot, for example, save a file or move data between workbooks on their own.

🎤 One-Line Interview AnswerA Sub performs an action while a Function returns a usable value, the Range object is how VBA reads and writes cells, and VBA earns its place over formulas whenever a task needs to loop over an unknown number of items, touch other applications, or perform actions like saving or formatting rather than just calculating a value.

Module 22 — Collaboration, Protection & Auditing

Co-authoring · Protect Sheet · Trace Precedents

▼

🛡️ Sharing and co-authoring

Saving a workbook to OneDrive or SharePoint enables real-time co-authoring, where multiple people can edit simultaneously and see each other's changes and cursor positions live, replacing the older, more fragile "Shared Workbook" feature. Comments (threaded, attached to a cell) are for discussion, while Notes (the older sticky-note style) are for static annotations — Excel now distinguishes the two clearly.

🔒 Protecting sheets and workbooks

Protect Sheet (Review > Protect Sheet) locks cells from editing by default and can be configured to still allow specific actions like sorting or using AutoFilter; it works together with the per-cell Locked property (Format Cells > Protection), so unlocking specific input cells before protecting the sheet lets users fill in only designated fields. Protect Workbook instead prevents structural changes like adding, deleting, renaming or reordering sheets. Track Changes (legacy, under Review) records who changed what and when, though modern co-authoring with version history has largely superseded it.

🔎 Formula auditing tools

Formulas > Trace Precedents draws arrows to every cell that feeds into the active formula, while Trace Dependents draws arrows to every cell that depends on it — both are essential before deleting or changing a cell in a complex workbook. Evaluate Formula steps through a calculation one operation at a time to show exactly where a result goes wrong, and the Watch Window keeps an eye on a cell's value while you work elsewhere in the workbook.

▼

📈 Designing a clean KPI layout

A good dashboard puts the most important 3-5 KPIs at the top in large, immediately readable numbers, groups related charts together, and uses consistent colors so the same color always means the same thing across every chart on the page (e.g. blue is always "actual," gray is always "target"). Module 24 — Interview Questions

Confident, Structured Answers

▼

Q: What's the difference between VLOOKUP and INDEX/MATCH?

VLOOKUP searches the first column of a range and returns a value from a column counted to its right by position, so it can only look rightward and breaks silently if a column is inserted and shifts that count. INDEX/MATCH separates the two jobs — MATCH finds the position, INDEX returns the value — by referencing the lookup and return ranges independently, so it can look in either direction and keeps working even if columns are inserted. I use INDEX/MATCH by default on any table I expect to change shape, and reach for VLOOKUP only on small, stable, throwaway lookups.

Q: How is XLOOKUP different from VLOOKUP, and why would you choose it?

XLOOKUP is the modern replacement that searches in either direction, defaults to an exact match instead of VLOOKUP's dangerous approximate-match default, and has a built-in "if not found" argument so I don't need to wrap it in IFERROR. It can also return an entire row or column of results at once instead of one value per formula. I use it in any workbook that will run on Excel 365 or 2021+; I fall back to INDEX/MATCH only when I need compatibility with older Excel versions.

Q: What's the difference between a relative, absolute and mixed cell reference?

A relative reference like A1 shifts when the formula is copied to a new cell, an absolute reference like $A$1 stays completely fixed, and a mixed reference like $A1 or A$1 locks only the column or only the row. I use absolute references for constants a formula needs to reuse everywhere it's copied, like a tax rate or a lookup table's start, and mixed references when building something like a multiplication table where one axis should move and the other shouldn't. Getting this wrong is the most common cause of a formula that looks right in one cell but returns garbage three rows down.

Q: When would you use a PivotTable instead of formulas like SUMIFS?

I reach for a PivotTable when I need to explore data interactively — slicing by multiple dimensions, drilling into details, or regrouping categories on the fly — because it does all of that through drag-and-drop with no formula maintenance. I use SUMIFS instead when the output needs to live inside a fixed report template, feed another formula, or sit next to narrative text where a Pivot's layout would be too rigid. In practice I often build both: a PivotTable to explore and validate the numbers, then SUMIFS formulas to hard-wire the final figures into a polished report.

Q: What causes a circular reference and how do you fix it?

A circular reference happens when a formula refers back to its own cell, either directly or through a chain of other cells that eventually points back to the start. The fix is almost always to find the broken link with Trace Precedents and rewrite the formula so it doesn't include its own cell in its range — for example, a SUM range that was accidentally dragged to include its own total cell. The one legitimate exception is enabling Iterative Calculation deliberately for specific modeling techniques, but that's rare and should be a conscious choice, not a default.

Q: How do you handle a VLOOKUP or XLOOKUP that can't find a match?

I wrap the lookup in IFERROR or, more precisely, IFNA, so a missing match shows a clear value like "Not found" instead of a scary #N/A error spreading into every formula downstream. XLOOKUP is even cleaner here because it has a built-in fourth argument for exactly this case, so I don't need an extra wrapper function at all. I prefer IFNA over a blanket IFERROR when I still want genuine formula bugs, like a wrong range, to surface instead of being silently hidden behind the same friendly message.

Q: What's the difference between COUNT, COUNTA and COUNTBLANK?

COUNT counts only cells containing numbers, COUNTA counts any non-empty cell regardless of whether it holds text, a number or a date, and COUNTBLANK counts cells that are genuinely empty. I use this trio together when auditing data completeness — comparing COUNTA against the total row count quickly tells me how many records are missing a value in a given column. A common mistake is using COUNT on a column of IDs stored as text, which returns zero even though every cell is clearly filled.

Q: What is a named range and why use one instead of a cell reference?

A named range gives a cell or range a readable label, like calling cell B1 "TaxRate," so formulas read as =Revenue*TaxRate instead of =C2*$B$1. Beyond readability, it also makes a workbook far easier to audit and maintain, because changing what a name points to updates every formula that uses it without hunting down each reference individually. I use named ranges for fixed single values like rates and thresholds, and Excel Table structured references for anything tabular that will grow with new rows.

Q: What's the difference between an Excel Table and a plain range?

An Excel Table, created with Ctrl+T, automatically extends formulas, formatting and filters to new rows as they're added, and exposes structured references like Sales[Amount] that stay valid no matter how many rows the table grows to. A plain range needs its formulas and formatting manually reapplied whenever rows are added, and any range reference baked into a VLOOKUP or SUMIFS has to be updated by hand. I convert any dataset that will receive new rows over time into a Table immediately, specifically so downstream PivotTables and charts update themselves automatically too.

Q: How would you remove duplicate records from a dataset?

For a quick one-time cleanup I use Data > Remove Duplicates and choose which columns define a "duplicate" — sometimes that's every column, sometimes just a key like email address. For something I need to keep dynamic or audit, I'd instead use a COUNTIF-based helper column or the UNIQUE dynamic array function, because both let me see and verify what's being treated as a duplicate before anything gets deleted. I always duplicate the sheet or keep a backup before running Remove Duplicates, since it's a destructive, non-reversible operation beyond one Undo.

Q: What's the difference between a calculated column and a measure in Power Pivot/DAX?

A calculated column is evaluated once per row and physically stored in the Data Model, which makes it the right choice when I need that value to filter, group or slice by. A measure is instead calculated on demand within whatever filter context a report currently applies, isn't stored per row, and is the correct tool for the vast majority of aggregations like totals, ratios and year-over-year comparisons. Using a calculated column where a measure belongs bloats the model's memory footprint and gives a static answer that doesn't respond correctly to slicers.

Q: What does CALCULATE do in DAX?

CALCULATE evaluates an expression inside a modified filter context, which means it can override, add to, or remove filters that would otherwise come from slicers, rows or columns in a report. It's the function nearly every advanced DAX pattern is built on — time intelligence functions like SAMEPERIODLASTYEAR or TOTALYTD are really just CALCULATE manipulating the date filter underneath. I think of CALCULATE as "take this measure, but evaluate it under this different set of conditions," which is the core mental model for comparisons like year-over-year or category-independent totals.

Q: What's Power Query and why would you use it over manual data cleanup?

Power Query (Get & Transform Data) imports and reshapes data through a recorded, ordered list of steps instead of one-off manual edits, so the entire cleaning process can be refreshed against new data later with one click. I use it whenever I'm combining multiple files with the same structure, joining related tables, or doing repetitive cleanup like removing columns, fixing types or splitting text — any of which would otherwise need to be redone by hand every time the source data updates. Because every step is visible and editable in the Applied Steps pane, it's also far more auditable than a spreadsheet that's been manually massaged.

Q: What is a slicer and how does it differ from a regular filter dropdown?

A slicer is a clickable button panel for a field's values that visually shows which filter is currently active, and unlike a column's filter dropdown, a single slicer can be connected to multiple PivotTables and PivotCharts at once through Report Connections. That's the mechanism that makes an Excel dashboard feel like a real interactive app — one click on a slicer updates every connected chart and table simultaneously. I use slicers specifically on dashboard sheets meant for someone other than the formula author to click through.

Q: How do you protect a worksheet so only certain cells can be edited?

First I select the specific input cells I want users to be able to edit and uncheck "Locked" in Format Cells > Protection, since every cell is locked by default. Then I apply Review > Protect Sheet, which activates that Locked property and prevents editing everywhere else, while still letting me permit specific actions like sorting or using AutoFilter if needed. This two-step order matters — protecting the sheet before unlocking the input cells leaves nothing editable at all.

Q: What's the difference between array formulas and dynamic arrays like FILTER and UNIQUE?

Older array formulas required confirming with Ctrl+Shift+Enter and had to be entered into a pre-sized range before you knew how many results would come back. Modern dynamic array functions like UNIQUE, FILTER and SORT automatically "spill" their results into as many neighboring cells as needed from one formula entered normally, and a trailing # reference lets other formulas track that spilled range as it grows or shrinks. I use dynamic arrays by default in any workbook on Excel 365, since they're simpler to write and self-maintaining compared to legacy CSE formulas.

Q: When would you use VBA instead of just writing more formulas?

I reach for VBA when a task needs to perform an action rather than calculate a value — saving a file, sending an email, formatting based on complex logic, or looping through an unknown number of sheets or workbooks — because formulas can only return values, not take actions. I also use it when a repetitive multi-step manual process needs to be automated into a single click for a non-technical user. For anything that's purely a calculation, even a complex one, I'd still prefer a formula or Power Query step over VBA, since formulas are easier for the next person to audit and don't require macro security settings.

Q: How do you audit a complex formula you didn't write?

I start with Trace Precedents to see every cell feeding into the formula, which immediately shows its full dependency chain, and Trace Dependents to see what else relies on it before I change anything. If the result still looks wrong, Evaluate Formula steps through the calculation one operation at a time so I can see exactly which part produces the unexpected value. For something I need to monitor while working elsewhere in the workbook, I'll add it to the Watch Window instead of repeatedly scrolling back to check it.

Q: What's your approach to building a dashboard that stakeholders will actually use?

I start by identifying the three to five KPIs that actually drive a decision, rather than cramming in every chart I could possibly make, and put those at the top in large, immediately readable numbers. I build every chart and PivotTable from the same underlying Table or Data Model and connect one set of slicers to all of them, so a single click updates the whole page instead of each chart needing separate filtering. I also keep colors consistent across every chart — the same color always means the same thing — and set up the print area and page scaling early so the dashboard exports cleanly to a one-page PDF when someone needs to share it outside Excel.

🎤 One-Line Interview AnswerI answer Excel interview questions the way I use the tool day to day: lead with the direct mechanism, back it with a concrete formula or example, and close with the trade-off that explains why I'd choose it over the alternative.
